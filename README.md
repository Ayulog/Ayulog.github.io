# Ayulog 的博客

记录生活、技术、游戏，以及一些慢慢积累的小事。这里是 [Ayulog 博客](https://ayulog.github.io/) 的源码仓库，文章以中文为主。

[访问博客](https://ayulog.github.io/) · [全部文章](https://ayulog.github.io/archives/) · [站内搜索](https://ayulog.github.io/search/) · [RSS](https://ayulog.github.io/rss.xml)

## 写些什么

- **[折腾](https://ayulog.github.io/setup/)**：Windows、NAS、网络与 PT。系统安装、容器部署、远程访问和下载做种。
- **[影音](https://ayulog.github.io/media/)**：媒体库、字幕、音频、蓝光 DIY 与压制。
- **[随笔](https://ayulog.github.io/notes/)**：不成篇的笔记。

分类只有一层，每篇文章属于一个分类，分类页按更新时间自动列出该分类的全部文章，不再人工维护索引页。

## 关于本站

博客由 [Ayulog](https://github.com/Ayulog) 维护，基于 [Astro](https://astro.build/) 和 [AstroPaper](https://github.com/satnaing/astro-paper) 主题，使用 TypeScript、Tailwind CSS 与 Pagefind，通过 GitHub Pages 发布。

支持明暗主题、全文搜索、标签与文章归档。文章和内容页面位于 [src/content/](src/content/)，配套配置示例位于 [public/examples/](public/examples/)。
