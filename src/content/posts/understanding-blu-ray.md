拿到一张蓝光碟，或者一份标着“原盘”的目录，动手前通常会先看几个核心信息：这是普通蓝光还是 UHD，盘上的正片对应哪个播放列表，以及为什么标称 50 GB 的碟在系统里显示为 46.6 GB。

本文先介绍光盘介质与影碟规格，再拆解蓝光电影在文件层面的目录结构；后续检查原盘、提取音轨和封装字幕，都建立在这些基础概念之上。相关软件汇总在[蓝光与媒体工具清单](/posts/media-diy-software/)。

## 蓝光是什么

蓝光光碟（**Blu-ray Disc**，缩写为 **BD**）与常见的 CD、DVD 一样，通常是直径 12 cm 的光盘，名称来自读写时使用的蓝紫色激光。

DVD 使用约 650 nm 的红色激光，而蓝光使用约 **405 nm** 波长的激光。结合光学系统与记录结构的改进，蓝光能够把信息排布得更紧密，在相同盘片尺寸下容纳更多数据（详见 [Blu-ray.com 的基础 FAQ][bluray-faq]）。

讨论蓝光时，可以从三个层面区分相关概念：

| 层面       | 关心的问题                       | 例子                           |
| ---------- | -------------------------------- | ------------------------------ |
| 光盘介质   | 存储容量、写入方式与光驱读写支持 | BD-ROM、BD-R、BD-RE            |
| 影碟规格   | 电影按什么标准组织目录和播放导航 | 普通 Blu-ray、Ultra HD Blu-ray |
| 文件与编码 | 音视频如何压缩、流数据如何封装   | M2TS、MKV、AVC、HEVC、TrueHD   |

蓝光光盘既可以作为数据盘存放任意文件，也可以按影碟标准制作成商业电影碟。符合 Ultra HD Blu-ray 规格的影碟包含完整的目录结构、导航程序与编码约束。此外，日常所说的“蓝光原盘”是指完整保留发行碟目录结构与封装数据的内容，其中的视频流在发行时已完成 H.264、HEVC 等有损压缩编码，并非未压缩的母版素材。

## 普通蓝光与 UHD 蓝光

日常提到的“蓝光”有时泛指整个 BD 家族，有时专指 1080p 普通高清蓝光。[Wikipedia 的 Blu-ray][wiki-bd] 和 [Ultra HD Blu-ray][wiki-uhd] 条目汇总了两代规格的核心差异：

| 项目           | 普通 Blu-ray                                | Ultra HD Blu-ray                       |
| -------------- | ------------------------------------------- | -------------------------------------- |
| 常见叫法       | BD、高清蓝光、1080p 蓝光                    | UHD BD、4K 蓝光                        |
| 画面规格       | 最高支持 1920×1080，也有 720p、1080i 等规格 | 支持最高 3840×2160、最高 60 帧每秒     |
| 视频编码       | MPEG-2、H.264 / AVC、VC-1                   | H.265 / HEVC                           |
| 色彩与动态范围 | 常规电影发行以 8bit SDR、BT.709 为主        | 支持 10bit、BT.2020 色彩信号和 HDR     |
| 常见电影碟容量 | 25 GB、50 GB                                | 66 GB、100 GB，规格也允许 50 GB        |
| 播放设备       | 支持普通蓝光的播放器                        | 需要明确支持 Ultra HD Blu-ray 的播放器 |

家用 UHD 蓝光的 4K 标准画布分辨率为 **3840×2160**（影院 DCI 4K 常见宽度为 4096 像素）；若影片采用宽银幕画幅，上下会保留黑边区域。

UHD 蓝光的 HDR 体系以 HDR10 为基础，部分发行版同时包含 Dolby Vision 或 HDR10+，具体规格以实际盘片的视频流信息为准。宣传语中的“4K 修复”或“4K 扫描”描述的是母版制作环节，最终载体既可能是 1080p 普通蓝光，也可能是 4K UHD 蓝光；反之，部分 UHD 蓝光是由 2K 中间片（DI）放大制作而成。

音轨规格与碟片世代相互独立。LPCM、Dolby TrueHD、DTS-HD Master Audio 以及 Atmos、DTS:X 音轨在普通蓝光和 UHD 蓝光中均可能出现。各类音轨标签的含义见[影视资源命名：音轨、字幕与容器](/posts/media-resource-naming/#音轨字幕与容器)。

## BD-ROM、BD-R 与 BD-RE

这组名称按光盘的物理记录特性划分：

| 类型       | 含义                                       | 常见用途                 |
| ---------- | ------------------------------------------ | ------------------------ |
| **BD-ROM** | 只读光盘，由工厂压制生产，无法通过光驱改写 | 商业发行的电影、游戏     |
| **BD-R**   | 一次写入型蓝光盘，已写入区域不可擦除重写   | 数据归档、刻录成品       |
| **BD-RE**  | 可擦写蓝光盘                               | 反复录制、测试和临时存储 |

选购光驱时需分别核对**读取**和**写入**规格。支持读取商业 BD-ROM 的光驱未必支持刻录大容量 BD-R 或 BD-RE，具体支持的介质类型、层数和读写速度应参考光驱完整型号的参数表。

此外，**BDXL** 常见于 100 GB、128 GB 等三层或四层可刻录蓝光介质，属于物理读写规格；而商业 UHD 蓝光影碟的读取与播放则取决于光驱和播放机对 Ultra HD Blu-ray 规范的支持。

## BD25、BD50、BD66、BD100 容量规格

这些简称对应盘片的标称容量（大致对应十进制 GB 数）：

| 常见称呼       | 标称容量 | 在电影碟中的常见对应                   |
| -------------- | -------- | -------------------------------------- |
| BD25           | 25 GB    | 普通蓝光，单层                         |
| BD50           | 50 GB    | 普通蓝光，双层；UHD 规格也允许这种容量 |
| BD66 / UHD66   | 66 GB    | UHD 蓝光，双层                         |
| BD100 / UHD100 | 100 GB   | UHD 蓝光，三层                         |

更大的盘片容量可以容纳更高码率的正片视频、多国语言音轨、花絮或不同剪辑版本，而实际正片体积则取决于盘内实际写入的数据量。比较不同发行版时，除了关注盘片容量，更需要对比母版来源、调色与压制编码质量。

标称 50 GB 的蓝光盘在电脑资源管理器中通常显示上限约为 46.6 GB，这源于十进制 `GB`（$1\text{ GB} = 10^9\text{ bytes}$）与二进制 `GiB`（$1\text{ GiB} = 2^{30}\text{ bytes}$）的换算差异。按二进制折算，25 GB 约为 23.3 GiB，50 GB 约为 46.6 GiB。

## 蓝光的 A、B、C 区码

普通蓝光使用 **A、B、C** 三个区域代码来管理发行地区的播放权限（DVD 则采用 1–6 等数字区码）。常见地区划分如下（详见 [Dell 的蓝光区码说明][dell-region]）：

| 蓝光区码 | 常见地区举例                                   |
| -------- | ---------------------------------------------- |
| **A 区** | 美洲、日本、韩国、中国香港、中国台湾及东南亚等 |
| **B 区** | 欧洲、中东、非洲、澳大利亚、新西兰等           |
| **C 区** | 中国大陆、俄罗斯、印度等                       |

商业发行碟可以设定为单区锁区，也可以做成多区或全区（ABC）。选购实体碟时，应核对具体发行版的碟盒背面标识或实测记录，确保与播放设备的区码匹配。

### UHD 蓝光的区码规则与套装碟片

**Ultra HD Blu-ray 规范未设普通蓝光的 A/B/C 区码限制**，绝大多数 UHD 碟片均为全区可播（极少数非标锁区案例记录于 [UHD 蓝光 Wiki][wiki-uhd]）。

需要注意的是，常见的“4K UHD + Blu-ray”双碟或多碟套装中，4K UHD 正片碟虽然无区码，但同盒附带的 1080p 普通蓝光正片碟或花絮碟仍遵循普通蓝光的 A/B/C 区码规则，在异区播放机上播放附赠碟片时仍需核对区码。

### Windows 光驱区域与蓝光区码机制

Windows 光驱属性页中的“DVD 区域”及剩余更改次数，对应的是光驱硬件固件里的 DVD RPC-2 区域控制（详见 [Wikipedia 的 DVD 区码说明][wiki-dvd-region]）。而在电脑上播放普通蓝光影碟时，A/B/C 区码的检查与切换通常由播放软件自身控制，与光驱属性页里的 DVD 区域设置相互独立。

## 实体碟播放链路与设备要求

完整播放一张商业蓝光实体碟，需要硬件与软件链路各环节协同配合：

| 环节       | 需要满足的条件                                                        |
| ---------- | --------------------------------------------------------------------- |
| 读取碟片   | 光驱硬件支持对应的 BD / UHD 介质、盘片层数与物理读取                  |
| 识别影碟   | 播放器支持相应的 HDMV / BD-J 导航与菜单解析                           |
| 内容保护   | 商业影碟具备 AACS / BD+ 等保护机制，播放环境需具备相应解密支持        |
| 解码音视频 | 软硬件支持视频编码（AVC / HEVC 等）、音频解码或源码直通以及图形字幕   |
| 输出到设备 | 显示器、电视、功放与连接线材支持目标分辨率、HDR、音频回传及 HDCP 协议 |

在设备上播放时需注意代际向下兼容关系：UHD 蓝光播放机通常向下兼容普通蓝光与 DVD，而仅支持“4K 升频输出”的普通 1080p 蓝光机只能将 1080p 画面拉伸输出为 4K 信号，无法读取 UHD 蓝光碟片。至于 CD、SACD 或特定刻录盘的兼容性，则以播放机说明书标注的规格为准。

### PC 端 UHD 光盘播放与 SGX 停服现状

早年 PC 端正规播放受保护的 UHD 蓝光实体碟，依赖特定代际 Intel CPU 的 SGX（Software Guard Extensions）硬件特性、主板设置、PowerDVD 特定版本及 HDCP 2.2 输出链路。

根据 [CyberLink 官方说明][cyberlink-uhd]，Intel SGX 验证服务器已于 **2025 年 4 月**停止运行，过往支持 UHD 蓝光的 PowerDVD 版本已无法通过在线验证播放受保护的 UHD 实体光盘。这一限制仅针对受保护的商业 UHD 光盘直接播放；已解密并整理到本地的 4K HEVC 视频、原盘目录或普通蓝光内容，仍可正常使用常规播放器解码观看。

## BDMV 原盘目录结构

进行蓝光 DIY 时，最常打交道的是 **BDMV 目录**。典型结构如下：

```text
Disc/
└── BDMV/
    ├── index.bdmv
    ├── MovieObject.bdmv
    ├── PLAYLIST/
    │   └── 00000.mpls
    ├── CLIPINF/
    │   ├── 00001.clpi
    │   └── 00002.clpi
    ├── STREAM/
    │   ├── 00001.m2ts
    │   └── 00002.m2ts
    └── BACKUP/
```

[VideoHelp 的蓝光结构说明][videohelp-bd] 列出了核心目录与文件的作用：

| 文件或目录         | 作用                                                          |
| ------------------ | ------------------------------------------------------------- |
| `index.bdmv`       | 影碟入口与顶层索引信息                                        |
| `MovieObject.bdmv` | HDMV 导航使用的 Movie Object 与控制命令                       |
| `PLAYLIST/*.mpls`  | 播放列表，定义播放片段的组合顺序、入出点区间与章节时间点      |
| `CLIPINF/*.clpi`   | 对应流文件的元数据、时间戳映射与流属性信息                    |
| `STREAM/*.m2ts`    | 存放复用后的音视频、PGS 图形字幕与交互菜单等实际流数据        |
| `BACKUP/`          | 导航文件、播放列表与流信息文件的备份目录（不包含 `.m2ts` 流） |

在包含 Java 交互菜单的盘片中，还会存在 `BDJO`、`JAR`、`AUXDATA` 以及根目录下的 `CERTIFICATE` 等文件夹，重制原盘时需完整保留这些关联目录。

### MPLS 播放列表与 M2TS 片段的关系

一部电影的正片可能保存在单个 `.m2ts` 文件中，也可能拆分成数十个 `.m2ts` 片段，由 `.mpls` 播放列表按特定顺序和入出点组合播放。同一张碟收录院线版与加长版（无缝分支，Seamless Branching）时，不同版本的播放列表会复用相同的公用片段，仅在差异段落引用各自的独立片段：

```text
00800.mpls → 00001.m2ts → 00002.m2ts（剧场版段落） → 00004.m2ts
00801.mpls → 00001.m2ts → 00003.m2ts（加长版段落） → 00004.m2ts
```

因此，直接打开体积最大的 `.m2ts` 或按文件名顺序拼接，往往会漏掉分支段落或打乱播放顺序。处理原盘的第一步是**用 BDInfo 扫描目录并结合实际播放核对正确的 `.mpls` 播放列表**，以此确定目标版本、完整时长、轨道列表与章节。

### M2TS 容器与内部音视频流

`.m2ts` 是蓝光使用的传输流容器格式，内部可同时封装视频流（AVC、VC-1、HEVC）、多条音轨以及 PGS 图形字幕。

蓝光内置的 PGS 字幕提取后通常保存为 `.sup` 二进制图形文件。若需修改字幕文字或转换为 `.srt` / `.ass` 文本字幕，需通过 OCR 工具识别转换，具体工具见[字幕软件清单](/posts/subtitle-software/)。

## 原盘、REMUX 与压制

这四种常见发布形式对应不同的整理阶段与体积特征：

| 形式              | 保存内容与处理方式                                   | 适用场景与特点                                         |
| ----------------- | ---------------------------------------------------- | ------------------------------------------------------ |
| **目录原盘**      | 保留 `BDMV`、`CERTIFICATE` 等完整光盘目录结构        | 适合保留原盘菜单、花絮与多版本分支，便于按目录直接修改 |
| **ISO 镜像**      | 将整张光盘的文件系统与目录打包为单个 `.iso` 镜像文件 | 便于单文件归档、挂载或刻录，内容取决于制作时的源目录   |
| **REMUX**         | 提取指定播放列表的原始音视频流与字幕，重新封装为 MKV | 保持原盘音视频画质无损，去除花絮与冗余音轨，兼容性更好 |
| **压制 / 重编码** | 使用 x264、x265 等编码器对视频或音频重新编码压缩     | 大幅缩减文件体积，画质表现取决于片源质量与编码参数     |

REMUX 在封装过程中直接复制原盘的压缩音视频码流，不经过视频重编码，因此画质与原盘正片完全一致；体积比整张原盘小，主要是因为去掉了花絮视频、非必要语种音轨以及菜单开销。有关发布名中 `BluRay`、`REMUX`、`2160p`、`HEVC` 等标签的含义，详见[影视资源命名：发布名、入库名与字幕](/posts/media-resource-naming/)。

## 开始 DIY 前的确认清单

拿到一张碟或一份原盘目录后，动手前先核对以下五项信息：

1. **碟片规格与载体**：区分 1080p 普通蓝光与 4K UHD 蓝光，确认手头是实体碟、BDMV 目录还是 ISO 镜像。
2. **发行版本与剪辑**：确认发行地区、片商与剪辑版本（如剧场版、导演剪辑版），以便匹配时间轴一致的音轨、字幕和章节。
3. **目标播放列表（MPLS）**：通过 BDInfo 确定正片对应的 `.mpls` 编号，查看是否包含多片段拼接或无缝分支。
4. **轨道与元数据构成**：记录视频编码、HDR / Dolby Vision 格式、原声与配音轨道以及字幕轨语言。
5. **成品输出形式**：明确最终是制作单文件 MKV（走 Remux 路线），还是保留原盘菜单与导航结构（走原盘 DIY 重制路线）。

完成信息核对后，可从 [DIY 工具清单](/posts/media-diy-software/)选择对应工具，或继续阅读[认识 HDR](/posts/understanding-hdr/)了解 UHD 片源中的 HDR10、HDR10+ 与杜比视界结构。
