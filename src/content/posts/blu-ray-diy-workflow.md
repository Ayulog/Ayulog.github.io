给一部蓝光影片补中文字幕，需要将影片版本、播放列表、字幕时间轴、图形字幕渲染和最终混流串联起来。本文以未加密的普通 1080p 蓝光 BDMV 目录为例，梳理从原盘检查到混流验收的完整流程。

在只新增字幕的前提下，最终成品的视频和音频均直接复用原盘码流；中间压制的小体积视频仅作为校对时间轴的工作副本。相关软件下载入口见[蓝光与媒体工具清单](/posts/media-diy-software/)和[字幕软件清单](/posts/subtitle-software/)。

## 确定成品目标与整体流程

动手前先明确最终要输出的成品形式，后半段的封装路线由目标决定：

| 成品目标                         | 后续混流路线                 | 核心工作内容                                      |
| -------------------------------- | ---------------------------- | ------------------------------------------------- |
| 保留原盘菜单、花絮与导航的蓝光盘 | 在原盘 BDMV 结构上重制       | 替换或追加 SUP 字幕轨，核对播放列表与菜单按钮关联 |
| 仅保留正片的精简蓝光结构         | 用 tsMuxer 重新混流生成 BDMV | 合并正片音视频、新 SUP 字幕与章节，生成无菜单新盘 |
| 便于本地或媒体库播放的 MKV       | 用 MKVToolNix 封装为单文件   | 封装音视频、ASS 或 SUP 字幕、章节与所需字体附件   |

整套工作流分为以下阶段：

```text
原盘副本 → 1. 确认影片版本、MPLS、轨道和章节
                ├─ 原始音视频与原盘结构 → 留给第 6 步最终混流
                └─ 完整正片节目 → 压制校对小片
                                      ↓
2. 准备字幕原稿 → 3. 校字与对轴 → 4. Aegisub 排版与多版本派生
                                      ↓
                5. 渲染转换：蓝光导出 SUP（PGS）；MKV 可用 ASS 或 SUP
                                      ↓
           6. 原始素材 + 新字幕 → 重制原盘 / 新建 BDMV / 封装 MKV
                                      ↓
                      7. 播放验收 → 8. 整理工程与交付
```

建议将目录划分为 `source/`（原盘备份）、`work/`（工作副本与中间素材）和 `output/`（最终成品），避免混流输出直接覆盖原始盘片。

## 第一步：检查原盘与播放列表

用 BDInfo 扫描原盘目录，确认目标发行版与剪辑版本，记录正片对应的 `.mpls` 播放列表、总时长、片段顺序、视频帧率、音轨、字幕轨和章节信息，并保存一份 BDInfo 报告备查。

根据正片的组织形式分别处理：

- **单片段正片**：确认目标 MPLS 引用的单个 `.m2ts` 编号及入出点，可直接将该文件或 MPLS 作为后续校对视频的提取源。
- **多片段拼接或无缝分支正片（俗称“肉酱盘”）**：一部正片由多个 `.m2ts` 片段按播放列表顺序拼接而成，或院线版与加长版共用部分片段。此时必须按目标 `.mpls` 提取完整节目（具体提取方式见[蓝光原盘 Remux：确认正确的播放列表](/posts/blu-ray-remux/#第一步确认正确的播放列表)）。
- **多条相近播放列表**：结合菜单实际进入的播放时长、多语种片头差异和章节分布确认目标 MPLS。

若最终目标是保留原盘菜单，此处提取出的完整视频仅用于压制校对小片，第六步重制时仍在原盘 BDMV 副本上操作。

## 第二步：准备字幕与规划轨道

字幕可从其他版本原盘提取，也可从 SubHD、字幕库等公开站点获取（见[字幕软件清单](/posts/subtitle-software/)）。拿到字幕后先保留一份未修改的原稿，并核对剪辑版本（如院线版、导演剪辑版或流媒体版片头差异）。若源字幕为 `.sup` 图形格式且需要修改文字或样式，先通过 OCR 转为文本字幕；若已有 `.srt` 或 `.ass`，则直接进入校对。

在对轴与排版前，先根据片源语种规划好要制作的字幕轨组合：

| 片源语种与素材条件         | 常用字幕轨配置                   | 制作要点                                         |
| -------------------------- | -------------------------------- | ------------------------------------------------ |
| 英语原声，具备准确中英文本 | 简英、繁英，按需附加纯简、纯繁   | 中英文逐句对齐，控制双行字数与显示时长           |
| 非英语原声，日常中文观看   | 简体中文、繁体中文               | 译文完整，确认片中外语标牌与穿插外语段落无漏译   |
| 保留外语原文字幕           | 保留原盘英文字幕或补充匹配文本轨 | 区分完整对白字幕、仅外语段落（Forced）与听障字幕 |

清理字幕中的无关广告或重复行时，注意保留原有的译者、校对与字幕组署名信息，避免误删片头片尾的正式字幕条目。

## 第三步：制作校对小片并对齐时间轴

当几十 GB 的原盘视频在字幕软件中拖动不够顺畅时，可用 HandBrake 或 ShanaEncoder 先压制一份小体积 MP4 作为校对工作片（具体参数见[字幕校对用的快速压片教程](/posts/handbrake-shanaencoder-subtitle-proxy/)）。压制校对小片需满足四项条件：

1. **完整时间线**：从第一步确认的目标 MPLS 提取，不裁剪片头片尾、不改变播放速度。
2. **保持画幅与黑边**：不开启自动裁黑边（Crop），不将原有字幕烧录进画面。
3. **选对参考音轨**：选择正片主原声音轨，避免误选评论音轨。
4. **保持原始帧率**：严格保持源片帧率（如 `23.976 fps` 或 `24 fps`），选择恒定帧率（CFR）。

将校对小片与字幕载入 Aegisub 或 Subtitle Edit，依次检查片头、中段、分支接缝与片尾的对白同步情况：

| 时间轴偏差现象                 | 校正方法                                                                  |
| ------------------------------ | ------------------------------------------------------------------------- |
| 全片固定提前或延后相同秒数     | 使用 [Aegisub 的 Shift Times][aegisub-shift] 整体平移时间                 |
| 片头同步，越往后偏差呈线性增大 | 核对字幕源与当前蓝光的帧率差异（如 25 fps 与 23.976 fps），按比例转换帧率 |
| 某一场景之后突然固定失步       | 定位剪辑差异点或无缝分支接缝，将该点之后的字幕分段平移                    |

确认同步后直接将修改保存到字幕工程文件中。

## 第四步：在 Aegisub 中排版与派生多版本

文字校对与时间轴定稿后，在 Aegisub 中统一设置字体、字号、描边、阴影与边距：

1. **建立分类样式**：为正片对白建立清晰的主样式（如中文 `MainCN`、英文 `MainEN`），屏幕招牌、顶部注释与片尾歌词分别使用独立样式，避免全选覆盖。
2. **核对脚本分辨率**：确认 ASS 脚本分辨率（如 `1920×1080`）与目标画布一致。若需转换分辨率，使用 [Aegisub 的重采样分辨率功能][aegisub-resolution]同步缩放坐标与字号（详细排版与特效做法见 [Aegisub 教程](/posts/aegisub-ass-effects/)）。
3. **派生多语种版本**：先完成一份基准双语稿（如简英），确认无重叠、出界或缺字后，再通过简繁转换和删除英文行派生出繁英、纯简、纯繁版本。
4. **复查各派生版本**：简繁转换后核对专有名词、人名与标点符号；单语版本确认删去英文行后未残留失效特效标签。

## 第五步：将 ASS 字幕渲染转换为 SUP

蓝光原盘标准使用 PGS（`.sup`）图形字幕。将定稿的 ASS 转换为 SUP 时，工具会把文字、字体与排版特效渲染为透明背景的序列图像并封装为字幕流（若最终目标是封装 MKV 且播放端支持 ASS，可直接封装 ASS 字幕与字体附件，跳过本步）。

常用的两条 ASS 转 SUP 路线如下（详细参数见[字幕的处理：第六步渲染并转回 SUP](/posts/subtitle-workflow/#第六步渲染并转回-sup)）：

- **一步转换路线**：使用 [ass2sup][ass2sup]（内部调用 Spp2Pgs，需在 PATH 中配置 `ffprobe` 并安装所需字体）或 [Subtitle Edit 的导出 Blu-ray SUP 功能][se-file]直接生成 `.sup` 文件。
- **分步渲染路线**：先用 [ass2bdnxml][ass2bdnxml] 将 ASS 渲染为 BDN XML 与序列 PNG 图像，再用 [SUPer][super] 编码为 `.sup` 流（便于检查中间图像与复杂特效）。对于保留旧版环境的项目，也可使用 `easyavs2bdnxml + avs2bdnxml` 输出 BDN XML 后编码。

在批量渲染全片前，先截取包含双行长句、顶部注释与渐变特效的短片段试转，并重点核对三项参数：

1. **渲染画布尺寸**：普通 1080p 蓝光与 4K UHD 蓝光的 PGS 字幕均按 **1920×1080** 画布渲染（UHD 播放时由播放器自动放大叠加到 2160p 画面）。注意不要让转换工具误按 720p 校对小片的尺寸缩小画布。
2. **目标帧率**：与原盘正片帧率严格一致（区分 `23.976` 与 `24.000`）。
3. **首尾显示与消失时间**：生成的每条 `.sup` 载入工具抽查，确认字幕按时出现与消失、无闪烁或截断，并按语言版本清晰命名（如 `chs_eng.sup`、`cht_eng.sup`）。

## 第六步：按成品目标混流

准备好原始原盘素材与校验无误的字幕文件后，按目标路线完成混流（更多蓝光编著工具对比见[蓝光原盘 DIY](/posts/blu-ray-diy/)）：

### 路线一：保留原盘菜单重制（以 BDFix 为例）

使用 Defsoft 的 BDFix（参考[历史产品资料][bdfix-info]）在现有未加密 1080p 原盘结构上替换或追加字幕轨：

1. 打开原盘工作副本，核对目标节目与原盘轨道列表。
2. 单片段正片可在 `M2ts Tree` 中选择对应文件；多片段或无缝分支正片则切换到 `Mpls Tree`，选中第一步确认的正片 `.mpls` 进行完整时间线处理。
3. 在轨道区选择**替换**不需要的外语字幕轨（可沿用原菜单按钮入口），或在 `New tracks` 中**追加**新 `.sup` 字幕轨，将语言标记设为中文（`chi` / `zho`），延迟保持为 0（已对好全片时间轴）。
4. 指定新的输出目录点击 **Build**，等待重制完成并检查日志（章节保留与复核方法见[章节的处理：BDFix Pro](/posts/media-chapters/#bdfix-pro重制现有蓝光时保留和复核章节)）。
5. 若采用了“追加新轨”或希望把原菜单上的外语按钮文字改为中文，还需进一步检查并修改菜单按钮映射（详见[蓝光原盘菜单修改篇](/posts/blu-ray-menu-editing/)）。

### 路线二：新建无菜单正片蓝光（tsMuxer）

不需要保留原盘菜单与花絮时，使用 [tsMuxer][tsmuxer] 生成精简的正片蓝光目录或 ISO：

1. 在 tsMuxer 中载入目标 `.mpls` 播放列表。
2. 勾选需要保留的视频、主音轨与原盘字幕，点击 **Add** 加入新制作的 `.sup` 字幕轨，设置语言标记为 `chi`（zh）。
3. 在 **Blu-ray** 页核对从 MPLS 自动带入的章节时间点（手动编辑方法见[章节的处理：tsMuxer](/posts/media-chapters/#tsmuxer生成蓝光结构时写入章节)）。
4. 输出选择 **Blu-ray folder** 或 **Blu-ray ISO**，指定新目录开始混流。

### 路线三：封装单文件 MKV（MKVToolNix）

面向本地播放器或媒体库时，在 MKVToolNix 中载入原盘 `.mpls`（或已提取的音视频流），加入新制作的 `.ass`（附带所用字体附件）或 `.sup` 字幕，设置语言、轨道名称（如 `简英双语`、`繁英双语`）与默认轨标记后混流输出（详见[蓝光原盘 Remux：第四步用 MKVToolNix 整理成品](/posts/blu-ray-remux/#第四步用-mkvtoolnix-整理成品)）。

## 第七步：检查成品目录与实际播放

混流完成后，先用 BDInfo 或 MediaInfo 扫描成品，核对视频、音频、字幕轨数量、时长与章节信息，再使用支持蓝光导航的播放器（或目标硬件播放机）从完整光盘目录 / ISO 入口实际播放验证：

| 检查点                     | 验收内容                                               |
| -------------------------- | ------------------------------------------------------ |
| 片头、中段与片尾           | 音画与字幕全程同步，无累积偏移                         |
| 无缝分支接缝处             | 跨越片段接缝时画面连贯、声音无卡顿、字幕无跳变         |
| 新增字幕轨切换             | 简英、繁英、纯简、纯繁顺序与轨道标记一致               |
| 复杂排版段落               | 双行长句、顶部注释与特效段落位置正常，无出界或残留     |
| 暂停、快进与章节跳转       | 跳转章节或快进后，字幕能正常刷新与清除                 |
| 菜单与按钮导航（重制原盘） | 主菜单、弹出菜单（Pop-up）与字幕切换按钮均指向预期轨道 |

## 第八步：整理成品与工程归档

验收通过后，按规范整理最终目录名称与文件名（命名规则见[影视资源命名](/posts/media-resource-naming/)），确保输出目录中只包含正式成品文件，不含校对小片、临时 PNG 或工程日志。

同时将本次制作的原始字幕、校对定稿 ASS、成品 SUP、所用字体包、BDInfo 报告及转换参数单独归档留存，便于后续维护或派生其他封装版本。
