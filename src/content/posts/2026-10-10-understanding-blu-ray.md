## 蓝光是什么

蓝光光碟的英文是 **Blu-ray Disc**，通常缩写为 **BD**。它和常见的 CD、DVD 一样，通常是直径 12 cm 的光盘；名称来自读写时使用的蓝紫色激光。

蓝光使用约 **405 nm** 波长的激光，DVD 则使用约 650 nm 的红色激光。结合光学系统和记录结构的改进，蓝光可以把信息排得更密，在相近的盘片尺寸里装下更多数据。[Blu-ray.com 的基础 FAQ][bluray-faq] 对这部分有直观说明。

这里需要分清三个层面：

| 层面       | 关心的问题                           | 例子                           |
| ---------- | ------------------------------------ | ------------------------------ |
| 光盘介质   | 能存多少、能不能写入、光驱能不能读取 | BD-ROM、BD-R、BD-RE            |
| 影碟规格   | 电影按什么规则组织和播放             | 普通 Blu-ray、Ultra HD Blu-ray |
| 文件与编码 | 数据怎么装、画面和声音怎么编码       | M2TS、MKV、AVC、HEVC、TrueHD   |

蓝光可以存电影，也可以存游戏或普通数据。把一个 4K 视频文件刻到蓝光数据盘上，只能说明盘里存着一个 4K 文件；它不会因此自动成为符合 Ultra HD Blu-ray 规格的影碟。

同样，**“蓝光原盘”也不是未压缩视频**。发行在蓝光上的电影，画面本来就经过视频编码压缩；原盘通常指保留发行碟的文件组织和内容，而不是摄影机素材或制作母版。

## 普通蓝光与 UHD 蓝光

日常说的“蓝光”有时泛指整个 BD 家族，有时专指普通高清蓝光。和 4K UHD 蓝光对比时，最好把两者写清楚。[Wikipedia 的 Blu-ray][wiki-bd] 和 [Ultra HD Blu-ray][wiki-uhd] 条目汇总了对应规格。

| 项目           | 普通 Blu-ray                                | Ultra HD Blu-ray                       |
| -------------- | ------------------------------------------- | -------------------------------------- |
| 常见叫法       | BD、高清蓝光、1080p 蓝光                    | UHD BD、4K 蓝光                        |
| 画面规格       | 最高支持 1920×1080，也有 720p、1080i 等规格 | 支持最高 3840×2160、最高 60 帧每秒     |
| 视频编码       | MPEG-2、H.264 / AVC、VC-1                   | H.265 / HEVC                           |
| 色彩与动态范围 | 常规电影发行以 8bit SDR、BT.709 为主        | 支持 10bit、BT.2020 色彩信号和 HDR     |
| 常见电影碟容量 | 25 GB、50 GB                                | 66 GB、100 GB，规格也允许 50 GB        |
| 播放设备       | 支持普通蓝光的播放器                        | 需要明确支持 Ultra HD Blu-ray 的播放器 |

家用 UHD 蓝光的 4K 画面宽度是 **3840 像素**；影院 DCI 4K 常见的宽度是 **4096 像素**，两者不能直接混写。影片有黑边时，有效画面也不一定填满整个 3840×2160 画布。

UHD 蓝光的 HDR 体系以 HDR10 为基础，也可包含 Dolby Vision 或 HDR10+。但**UHD 不等于每张碟都带 Dolby Vision，4K 也不等于一定有 HDR**，仍要看具体发行版和实际视频信息。BT.2020 是色彩信号所用的范围，也不表示一张碟的画面真的覆盖了整个 BT.2020 色域。

“4K 修复”“4K 扫描”和“4K UHD 蓝光”也有区别。前两者可能描述母版的制作过程，最后发行的仍可能是一张 1080p 普通蓝光；反过来，一张 UHD 蓝光也可能使用由较低分辨率中间片放大的画面。

音轨同样要单独看。LPCM、Dolby TrueHD、DTS-HD Master Audio，以及 Atmos、DTS:X 等标记，不是 UHD 碟片独占。普通蓝光也可能带有无损或沉浸式音轨，UHD 蓝光也不保证一定有这些音轨。音轨标记的区别见资源命名一文中的[音轨、字幕与容器](/posts/2026-10-10-media-resource-naming/#音轨字幕与容器)。

## BD-ROM、BD-R 与 BD-RE

这组名称描述的是盘片如何记录数据，与 1080p、4K 不是同一种分类。

| 类型       | 含义                                           | 常见用途                 |
| ---------- | ---------------------------------------------- | ------------------------ |
| **BD-ROM** | 只读，通常由工厂复制生产，不能用家用刻录机改写 | 商业发行的电影、游戏     |
| **BD-R**   | 一次写入型蓝光盘，已写入的区域不能擦除重写     | 数据归档、刻录成品       |
| **BD-RE**  | 可擦写蓝光盘                                   | 反复录制、测试和临时存储 |

BD-R 的“一次写入”指记录区域不能反复擦写，不是说任何情况下都只能执行一次刻录操作；能否追加数据，还要看刻录方式和盘片是否已经封盘。

买光驱时还要区分**读取**和**写入**能力。能读取 BD-ROM 的光驱不一定能刻录 BD-R，更不一定支持所有 BD-RE 或大容量盘片。具体支持哪些介质、层数和速度，应看完整型号的规格表。

另外还有 **BDXL**，常见于 100 GB、128 GB 等大容量蓝光记录介质。它和 UHD 蓝光不是同义词：**支持 BDXL，不足以证明整套设备就能播放商业 UHD 影碟**；也不能因为两张盘都标 100 GB，就认为它们的用途和兼容性完全相同。

## BD25、BD50、BD66、BD100 指什么

这些通常是按标称容量使用的简称，数字大致对应 GB 数量。

| 常见称呼       | 标称容量 | 在电影碟中的常见对应                   |
| -------------- | -------- | -------------------------------------- |
| BD25           | 25 GB    | 普通蓝光，单层                         |
| BD50           | 50 GB    | 普通蓝光，双层；UHD 规格也允许这种容量 |
| BD66 / UHD66   | 66 GB    | UHD 蓝光，双层                         |
| BD100 / UHD100 | 100 GB   | UHD 蓝光，三层                         |

这张表限定在电影碟语境。单看“BD100”字样，还需要确认说的是 UHD 发行碟，还是 BDXL 等记录介质。

容量增加可以容纳更高码率的视频、更多音轨、花絮或不同剪辑，但**BD100 不是画质等级，BD50 也不表示正片文件一定有 50 GB**。同样的电影，发行版的母版、修复、调色和编码处理，往往比容量标签更值得比较。

还有一个常见疑问：标着 50 GB，电脑里为什么只有约 46.6？这是十进制 GB 与二进制 GiB 的计量差异。容量标称通常按 `1 GB = 10⁹ bytes`，而 `1 GiB = 2³⁰ bytes`；有些系统按二进制换算，却仍在界面上写 GB。

因此，25 GB 大约对应 23.3 GiB，50 GB 大约对应 46.6 GiB。这种差异本身不代表盘片缩水；实际文件占用还要另看盘上写入了多少内容。

## 蓝光的 A、B、C 区码

区码用来限制影碟在哪些区域的播放设备上播放。**普通蓝光使用 A、B、C，DVD 常见的是数字区码；两套编号不能互相套用。**

下面列的是常见地区举例，并非完整国家和地区清单，可结合 [Dell 的蓝光区码说明][dell-region] 查看。

| 蓝光区码 | 常见地区举例                                   |
| -------- | ---------------------------------------------- |
| **A 区** | 美洲、日本、韩国、中国香港、中国台湾及东南亚等 |
| **B 区** | 欧洲、中东、非洲、澳大利亚、新西兰等           |
| **C 区** | 中国大陆、俄罗斯、印度等                       |

但这不等于“正版蓝光一定锁区”。发行方可以只允许一个区，也可以允许多个区或全部区域。购买时应核对**具体发行版**的碟盒、盘面和发行说明，必要时查看可靠的实测记录；不能只凭“美版”“日版”或售卖地区下结论。

例如，一台只支持 B 区普通蓝光的播放机，不能因为同样使用 HDMI，就播放一张限制在 A 区的普通蓝光；如果那张碟本身允许 A、B、C 三个区，则没有这项区码障碍。

### UHD 蓝光的“无区码”要看哪张碟

**Ultra HD Blu-ray 规格没有采用普通蓝光的 A/B/C 区码机制。** 不过，这句话说的是 UHD 碟片本身，不是整盒里所有附赠光盘，也不是说 UHD 播放机播放任何格式都不受区码限制。

常见的“4K UHD + Blu-ray”套装里，4K 正片与附赠的普通蓝光是两张不同的盘。UHD 盘可播放，不代表普通蓝光上的正片或花絮也一定能播放；附赠 DVD 则还要按 DVD 的区码规则判断。

少量 UHD 发行版也曾被报告存在额外的区域检测或兼容问题，[UHD 蓝光 Wiki][wiki-uhd] 记录了这类例外。因此，购买进口碟时仍可以查一下具体版本，但不应把个别例外写成 UHD 普遍采用 A/B/C 锁区。

### Windows 的“DVD 区域”不是蓝光区码

Windows 光驱属性里的“DVD 区域”和剩余修改次数，主要涉及 DVD 的 RPC 区域控制，不能拿来判断蓝光的 A/B/C 区码。

对电脑上的普通蓝光播放，区域判断通常由播放软件处理；软件也可能限制区域选择和修改次数。DVD 的 RPC-2 则涉及光驱固件中的区域设置。这正是为什么“光驱区域”“软件区域”和“碟片区域”不能混成一件事。[Wikipedia 对两者的区别有说明][wiki-dvd-region]。

看到商家写“全区光驱”，先弄清它指的是 DVD、普通蓝光还是 UHD，是硬件能力、播放软件的能力，还是店家附带的处理方案。仅凭“全区”两个字，不能判断完整的播放兼容性。

## 光驱能读，不等于电影能播

一张实体蓝光电影播放出来，至少要经过几层支持：

| 环节       | 需要确认什么                                                          |
| ---------- | --------------------------------------------------------------------- |
| 读取碟片   | 光驱支持对应的 BD / UHD 介质、层数和盘片类型                          |
| 识别影碟   | 播放器支持相应的电影规格、导航与菜单                                  |
| 内容保护   | 商业影碟涉及 AACS 等机制，需要适用的播放支持                          |
| 解码音视频 | 支持碟片中的视频、音轨和字幕格式                                      |
| 输出到设备 | 显示器、电视、功放与连接链路支持所需的分辨率、HDR、音频及 HDCP 等要求 |

因此，电脑里能看见光盘文件，不代表某个视频播放器就能直接播放完整影碟；能打开一个 M2TS 文件，也不等于能够运行菜单、正确选择版本或处理商业碟的内容保护。

普通 DVD 光驱不能读取蓝光。普通蓝光播放机也不能仅靠“支持 4K 升频”就播放 UHD 蓝光：升频是把已有画面转换到更高输出分辨率，与支持 UHD 影碟是两回事。

UHD 蓝光播放机通常也支持普通蓝光和 DVD，但其他格式的兼容性应逐项看说明书。不能从“支持 UHD”直接推导出它一定支持 CD、VCD、SACD 或所有刻录盘。

### 电脑播放的旧教程需要按时间核对

早年的正版 UHD 蓝光电脑播放方案，对 Intel SGX、软件版本和输出链路有特定要求。旧文里的“买某代 CPU 或某张显卡就能播”，不能直接当成今天的采购建议。

截至本文核对资料时（2026 年 10 月），[CyberLink 官方说明][cyberlink-uhd]：Intel SGX 验证服务器已于 **2025 年 4 月**停止运行，过去支持 UHD 蓝光的 PowerDVD 版本也无法再按该方案完成播放；即使保留原本兼容的 SGX 硬件，也不能解决这一问题。

**这项变化针对受保护的 UHD 蓝光光盘播放，不等于电脑不能播放本地 4K / HEVC 视频，也不等于普通蓝光播放全部失效。** 选设备和软件时，先明确自己要播放的是实体碟、原盘目录、ISO，还是已经整理好的媒体文件。

电脑与独立播放机也没有仅由设备类别决定的画质排名。解码、色彩输出、HDR 处理和显示设备是否设置正确，才是需要具体检查的内容。

## 打开原盘目录，会看到什么

对于 DIY，接下来最常接触的是 **BDMV 目录**。下面只是简化示例，不是每张碟的完整文件清单；文件编号也不代表某部实际影片。

```text
Disc/
└── BDMV/
    ├── index.bdmv
    ├── MovieObject.bdmv
    ├── PLAYLIST/
    │   └── 00000.mpls
    ├── CLIPINF/
    │   ├── 00001.clpi
    │   └── 00002.clpi
    ├── STREAM/
    │   ├── 00001.m2ts
    │   └── 00002.m2ts
    └── BACKUP/
```

[VideoHelp 的蓝光结构说明][videohelp-bd] 列出了这些目录和文件的基本用途：

| 文件或目录         | 作用                                                     |
| ------------------ | -------------------------------------------------------- |
| `index.bdmv`       | 影碟的索引信息                                           |
| `MovieObject.bdmv` | HDMV 导航使用的 Movie Object 与相关命令                  |
| `PLAYLIST/*.mpls`  | 播放列表，组织要播放的片段及其播放区间，并包含章节等信息 |
| `CLIPINF/*.clpi`   | 对应片段的流信息和时间定位等信息                         |
| `STREAM/*.m2ts`    | 存放复用后的音视频、图形字幕等流数据                     |
| `BACKUP/`          | 部分导航和信息文件的备份，并不是正片再复制一份           |

其他碟片还可能出现 `BDJO`、`JAR`、`AUXDATA`、`CERTIFICATE` 等目录，用于 BD-J 交互程序、辅助数据或相关信息。不能因为没在简化示例里列出，就随意删除。

### 为什么不能只找最大的 M2TS

一部电影可能完整放在一个 M2TS 中，也可能分成多个片段，由 MPLS 播放列表指定顺序和取用范围。同一张碟上的不同剪辑版本，还可能复用部分片段；这与无缝分支等制作方式有关。

假设一个虚构播放列表依次引用：

```text
00000.mpls → 00001.m2ts 的一段 → 00002.m2ts 的一段 → 00001.m2ts 的另一段
```

播放列表本身很小，真正的音视频数据在 M2TS 中。只打开最大的 M2TS，可能看到正片的一部分，也可能丢失分支、章节或正确的拼接顺序。按文件名排序后直接拼接，同样没有遵循播放列表。

所以，DIY 的起点通常是**确认正确的播放列表、时长、版本与轨道**。可先用 BDInfo 查看结构，再结合正常播放结果核对。最大的文件、最长的列表都只能当线索，不能作为对所有影碟通用的选择规则。

### M2TS 是容器，不是视频编码

一个 M2TS 文件可以同时装着视频、多个音轨和 PGS 图形字幕等数据。扩展名是 `.m2ts`，不能据此判断画面使用 AVC、VC-1 还是 HEVC，也不能得知哪条音轨是国语。

蓝光常见的 PGS 字幕是图形字幕，提取时常见 `.sup` 文件；它不是改扩展名就能变成文字的 SRT。字幕提取和 OCR 另见[字幕常用软件与资料](/posts/2026-10-10-subtitle-software/)。

## 原盘、REMUX 与压制

这些词描述内容怎样保存和处理，不是另一套光盘容量规格。

| 形式              | 通常保留什么                                           | 需要注意什么                                            |
| ----------------- | ------------------------------------------------------ | ------------------------------------------------------- |
| **目录原盘**      | 以目录形式保存影碟结构，蓝光常见 `BDMV` 等目录         | 是否完整，仍要看制作说明和实际文件                      |
| **ISO 镜像**      | 用一个镜像文件承载光盘的文件系统和内容                 | `.iso` 只是镜像形式，不保证内容完整、未改动或可直接播放 |
| **REMUX**         | 按节目提取所需轨道后重新封装，通常不重编码所选音视频流 | 常见输出为 MKV，通常不保留原盘菜单和全部花絮            |
| **压制 / 重编码** | 对视频或音频进行新的编码，按目标调整体积和规格         | 耗时、体积与质量取决于源材料、编码器和参数              |

对同一张碟、同一条视频流，如果 REMUX 过程没有重新编码或修改视频数据，就不会因为“装进 MKV”而增加一轮视频编码损失。但这不表示文件保留了整张碟的全部信息；丢弃音轨、字幕、菜单或 HDR 相关数据，仍会改变最终使用体验。

REMUX 变小，可能只是少了花絮、其他语言音轨和容器开销。文件体积减少本身不能证明视频被压制；反过来，写着 REMUX 的文件名，也不能替代对实际轨道和制作说明的检查。

资源名称里的 `BluRay`、`REMUX`、`2160p`、`HEVC` 等字段，详见[影视资源命名：发布名、入库名与字幕](/posts/2026-10-10-media-resource-naming/)。

## 开始 DIY 前先确认什么

拿到一张碟或一份原盘后，可以先记下这几项：

1. **对象是什么**：普通蓝光还是 UHD 蓝光，实体碟、目录还是 ISO。
2. **是哪一个发行版**：地区、发行商、剪辑版本和时长；不同版本的字幕、章节和音轨不一定能直接通用。
3. **节目怎么组成**：正片对应哪个 MPLS，是否引用多个片段，有没有不同剪辑或角度。
4. **实际带了什么轨道**：视频编码、音轨语言、字幕类型，以及需要保留的 HDR 信息。
5. **准备输出到哪里**：保留原盘菜单、只做单文件 REMUX，还是为特定设备重新编码。

如果只是把所需音视频和字幕整理进 MKV，重点是选对节目、保持同步并核对轨道。若要做能在影碟机上按菜单播放的蓝光结构，还会涉及导航、菜单和制盘兼容性，两者的工作量并不相同。

完成这些确认后，再进入 [DIY 工具清单](/posts/2026-10-10-media-diy-software/)，按原盘检查、分流和重新封装的顺序选择工具。
