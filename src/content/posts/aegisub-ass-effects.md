字幕要跟着画面移动、逐字变色，或者拿一张 PNG 当底板时，单靠 SRT 的起止时间不够，需要把定位和动画写进 ASS。ASS（Advanced SubStation Alpha）把文字、样式、时间轴、定位、绘图和动画标签放在同一个脚本里，Aegisub 负责编辑，最终画面由字幕渲染器解释；编辑器预览、播放器外挂字幕和压制工具用的渲染器不一致时，同一份 ASS 也会出现差异。

制作从可用的基础工程开始，再逐层加入覆盖标签、矢量绘图和卡拉 OK；PNG 挂图放在最后，用到的 `\1img` 是 VSFilterMod 扩展。内容按 **2026 年 10 月 11 日**核对的 Aegisub 官方文档与 VSFilterMod 公开源码整理，实际效果要在目标渲染器里回看。

## 一个字幕事件由四层组成

一个特效字幕事件通常同时涉及四件事：

1. **文字和时间**：对白、歌词或画面文字，以及出现和消失的时间。
2. **样式**：字体、字号、颜色、描边、阴影、对齐方式和边距。
3. **覆盖标签**：写在 `{}` 中，对单条事件或其中一段文字临时改位置、颜色和动画。
4. **渲染器**：负责解释这些标签。`libass`、VSFilter 和 VSFilterMod 的支持范围并不完全相同。

制作时可以按下面的顺序保存中间结果：

```text
原始字幕或台词
    ↓ 校对文字与时间
基础 ASS（样式、位置、换行）
    ↓ 加入覆盖标签、绘图或模板
特效 ASS + 字体 + 图片（如有）
    ↓ 用目标渲染器检查
外挂字幕 / 压制后的字幕
```

先让普通字幕在画面上正确出现，再加动画。这样某个标签失效时，比较容易判断问题来自时间轴、样式还是渲染器。

## 在 Aegisub 里建立基础工程

### 设置脚本画布

打开字幕后，在脚本属性里确认 `PlayResX` 和 `PlayResY`。它们是 ASS 坐标系的宽高，`\pos(960,540)` 的坐标指的是这块画布，而不是 Windows 桌面的像素位置。视频比例、裁切或脚本画布改变后，原来的坐标都应该重新检查。

加载视频和音频，先用一条普通对白测试。使用视频区域旁的可视化排版工具拖动位置，再回到文本框查看它生成的标签。

### 先建样式，再做单条覆盖

在样式管理器中建立对白、双语、注释和歌词等基础样式。常用设置包括：

- 字体和字号：先确认目标机器或封装文件中有这套字体。
- 主色、边框色和阴影色：白字遇到浅色背景会看不清，描边通常比盲目加粗更稳。
- 对齐方式和边距：`\an1` 到 `\an9` 决定锚点，底部居中常用 `\an2`。
- 描边和阴影：复杂特效可以把基础样式设得简单，另用覆盖标签做局部变化。

字体收集器只负责把字体文件收集到一起；播放时用的是不是同一版字体，仍要在实际播放环境回看。

## 常用 ASS 标签与特效代码

常用标签列在下表，可以直接在 Aegisub 的单条事件里试写。除 `\N` 直接写在文字中，覆盖标签都应放进 `{}`。颜色覆盖标签使用 `&HBBGGRR&`，也就是蓝、绿、红的顺序，与网页常见的 RGB 相反；透明度要另用 `\alpha` 或 `\1a` 等标签设置，不要把样式字段中的 `&HAABBGGRR` 直接搬到 `\1c` 后面。

| 标签                       | 作用                       | 示例或注意事项                                                                                                        |
| -------------------------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `\N`                       | 强制换行                   | `第一行\N第二行`。                                                                                                    |
| `\r`、`\rEng`              | 重置样式                   | `\r` 恢复本条事件在 Style 栏指定的样式；`\rEng` 切换到已存在的 `Eng` 样式。两者都会取消其后文字原有的样式覆盖和动画。 |
| `\an`                      | 设置九宫格对齐锚点         | `\an7` 左上、`\an2` 底部居中。                                                                                        |
| `\pos`                     | 固定位置                   | `\pos(960,900)`。                                                                                                     |
| `\move`                    | 在时间段内移动             | `\move(300,900,1600,900,0,1200)`；末两项是相对本条事件开始的毫秒数。                                                  |
| `\fs`、`\fsp`              | 字号、字间距               | `\fs50\fsp15`。                                                                                                       |
| `\fscx`、`\fscy`           | 横向、纵向缩放             | `\fscx80\fscy120`；100 表示 100%。                                                                                    |
| `\frx`、`\fry`、`\frz`     | 绕 X、Y、Z 轴旋转          | `\frz10`；单位为度。                                                                                                  |
| `\fax`、`\fay`             | 沿 X、Y 轴错切             | `\fax0.05`；0 表示不变形。这两个标签属于常见 ASS 标签，不是 VSFilterMod 专有扩展。                                    |
| `\bord`、`\shad`           | 描边、阴影大小             | `\bord2\shad0`。                                                                                                      |
| `\1c`、`\2c`、`\3c`、`\4c` | 主色、次色、描边色、阴影色 | `\1c&H786E5D&\3c&H000000&`；`\c` 等同于 `\1c`，次色主要用于卡拉 OK。                                                  |
| `\alpha`、`\1a` 至 `\4a`   | 整体或各颜色层的透明度     | `\alpha&H80&`；`00` 完全不透明，`FF` 完全透明。                                                                       |
| `\blur`                    | 模糊边缘                   | `\bord2\blur3` 模糊描边；`\bord0\blur3` 模糊字形边缘。是否有描边由 `\bord` 决定，`\3c` 只改描边颜色。                 |
| `\fad`                     | 淡入淡出                   | `\fad(120,200)` 表示开头 120 ms 淡入、结尾 200 ms 淡出。                                                              |
| `\t`                       | 在时间段内变换标签         | `\t(0,800,\fscx120\fscy120)`；只支持可动画的标签。                                                                    |
| `\clip`                    | 只显示裁剪区域             | `\clip(0,0,960,1080)`。                                                                                               |
| `\p1`、`\p0`               | 进入、退出矢量绘图模式     | `\p1` 后接 `m`、`l` 等绘图命令。                                                                                      |

例如，下面的事件把文字放到画布左上区域，设置白字、黑色描边，并在 800 毫秒内放大：

```text
Dialogue: 0,0:00:01.00,0:00:03.00,Default,,0,0,0,,{\an7\pos(120,120)\fs48\1c&HFFFFFF&\3c&H000000&\bord2\shad0\t(0,800,\fscx120\fscy120)}标题
```

`\t` 里的开始时间和结束时间相对于本条字幕事件计算；省略时间时，则覆盖整段事件。`\move` 和 `\pos` 互斥：需要移动时保留 `\move`，需要定点时保留 `\pos`。

### VSFilterMod 扩展单独记

下面这些标签不属于通用 ASS 标签。VSFilterMod 源码中有对应实现，但播放器或 Aegisub 使用其他渲染器时可能直接忽略它们。

| 标签               | 作用                   | 示例或注意事项                                                                            |
| ------------------ | ---------------------- | ----------------------------------------------------------------------------------------- |
| `\fsvp`            | 调整后续字形的垂直偏移 | `\fsvp8`；所核对的 VSFilterMod 实现中正值上移、负值下移，只作用于后续字形，不是段落行距。 |
| `\1vc`             | 四角渐变主色           | `\1vc(&H0000FF&,&H00FF00&,&HFF0000&,&HFFFFFF&)`；四个颜色依次对应左上、右上、左下、右下。 |
| `\1img` 至 `\4img` | 用 PNG 纹理填充颜色层  | 如 `\1img(panel.png)`；使用方法见后面的挂图示例。                                         |

### 用三个事件做一条带边框的文字

这组写法用两条 `█` 事件做背景和边框，第三条才显示文字。下面的坐标以 **1920×1080 脚本画布**为例，三条事件的起止时间完全相同，Layer 分别设为 **0、1、2**；Layer 数字越大，越靠上显示。第一、二条保留 `█`，只把第三条的正文换成要显示的内容。

```text
Dialogue: 0,0:00:01.00,0:00:03.00,Default,,0,0,0,,{\fscx2400\fscy100\an3\fs56\1c&H000000&\alpha&HE4&\bord0\shad0\b0\pos(1312.534,928.334)}█
Dialogue: 1,0:00:01.00,0:00:03.00,Default,,0,0,0,,{\fscx2400\fscy100\an3\fs56\1a&HFF&\3a&H00&\bord5\3c&H507782&\shad0\b0\pos(1312.534,928.334)}█
Dialogue: 2,0:00:01.00,0:00:03.00,Default,,0,0,0,,{\an3\fs50\1c&HFFFFFF&\alpha&H00&\bord0\shad0\b1\pos(1290,928)}示例标题文字
```

Layer 0 是半透明黑底，Layer 1 隐藏方块填充、只留下不透明描边，Layer 2 是实际文字。第一、二条应使用同一个包含 `█` 字形的字体。方块的宽度和基线会随字体变化，换画布或字号后需要重新定位；`\fscx2400` 也只是这组示例的横向拉伸比例。

如果目的是一个尺寸明确的矩形背景，可以直接用下一节的 `\p1` 绘图替代两条方块事件，给背景和文字分别设 Layer，便于修改宽高与边距。

## 用 `\p1` 做可复用的矢量图形

矢量绘图不需要额外图片文件，适合做色块、线条、圆形和简单遮罩。进入绘图模式后，文字字段不再按普通文字解释：

```text
Dialogue: 0,0:00:01.00,0:00:03.00,Default,,0,0,0,,{\an7\pos(100,100)\p1\bord0\shad0\1c&H3B82F6&}m 0 0 l 240 0 l 240 64 l 0 64
```

这里的 `m` 是移动到起点，`l` 是连到下一个点。四个点组成一个宽 240、高 64 的矩形，尺寸使用脚本坐标。事件到这里结束时不必额外补 `\p0`；若在同一事件后继续写普通文字，再用 `{\p0}` 退出绘图模式。做字幕底板时，通常把矩形和文字拆成两条同起止时间的事件，让文字使用更高的 Layer。

矢量图形的坐标也受 `\pos`、`\an`、`\fscx` 和 `\fscy` 影响。先做静态图形，再加 `\t` 改变缩放或颜色，比较容易控制边界。

## 卡拉 OK：先切音节，再套模板

卡拉 OK 标签的时间单位是百分之一秒。例如：

```text
{\k20}你{\k30}好
```

表示“你”持续 0.20 秒，“好”持续 0.30 秒。实际制作应在音频波形上切出音节，而不是把整句的起止时间平均分配。`\k`、`\K`、`\kf` 和 `\ko` 的填充方式不同，先用两三个音节确认渲染器的表现，再批量处理。

Aegisub 自带 Karaoke Templater，用模板批量生成逐字特效。可以从官方的 [Karaoke Templater 文档](https://aegisub.org/docs/latest/automation/karaoke_templater/) 开始：先为歌词切分音节，再建立模板注释行，通过“自动化 → 应用卡拉 OK 模板”生成事件。

模板的声明写在 Effect（特效）栏，样式名称、音节时间和事件结构都参与生成结果。导入第三方模板前先读说明、检查脚本来源与许可，生成后展开检查事件，避免样式名或画布不一致时批量输出错误位置。

[Aegisub Karaoke Effect 481 Templates](https://github.com/Seekladoom/Aegisub-Karaoke-Effect-481-Templates) 是第三方模板整理仓库，README 标明转载自 `huyhuu.com`。可以用来观察模板结构；具体脚本和素材的使用、再分发仍需确认原作者的许可与署名。

套用双语模板的操作还可参考[《使用 Aegisub 套用模板制作双语特效字幕教程》](https://air.moe/archives/792)。该文发表于 2022 年，流程是先切分歌词音节并对齐音频，再复制模板注释行、匹配样式，通过“自动化 → 应用卡拉 OK 模板”生成事件；菜单名称按当时的 Aegisub 版本记录。

## 进阶：用 PNG 做字幕挂图

### 先确认这是扩展功能

挂图示例使用 `\1img`、`\2img`、`\3img`、`\4img` 把 PNG 当作不同颜色层的纹理。它们不是标准 ASS 标签，通常需要 VSFilterMod 或兼容的 VSFilterMod 渲染组件；Aegisub 预览也必须选择同一类字幕源，普通 `libass` 播放器可能直接忽略这些标签。

不要把 DLL 从陌生压缩包直接放进生产环境。先确认来源、位数和所用 Aegisub/渲染器是否匹配，并准备一条普通 ASS 作为回退。图片挂图只适合明确控制播放环境的场景；需要发给不确定播放器的字幕时，优先使用标准标签、矢量绘图或预渲染成图形字幕。

外挂播放的设置见 [PotPlayer 和 MPC-HC 挂载 VSFilterMod 加载外挂特效字幕](/posts/vsfiltermod-external-subtitles/)，其中列出了两个播放器的滤镜配置与回看方法。

### 用矩形绘图区域填充 PNG

核心思路是用 `\p1` 画出与 PNG 尺寸相同的矩形，再让 `\1img` 填充这个区域。将下面示例中的 `panel.png` 与 ASS 放在同一目录；所核对的 VSFilterMod 实现会尝试相对字幕文件目录寻找图片。

```text
Dialogue: 0,0:00:02.00,0:00:05.00,Default,,0,0,0,,{\an7\p1\pos(888,784)\bord0\shad0\1img(panel.png)}m 0 0 l 880 0 l 880 226 l 0 226
```

这里的 `880×226` 应与准备好的 PNG 尺寸对应；`\an7` 把定位锚点明确设在左上，`\pos(888,784)` 给出它在脚本画布中的位置。`\1img` 代表主色层，其他数字分别对应第二颜色、边框和阴影层。图片要保留透明背景；如果图片比绘图区域小，纹理可能重复平铺或被裁切，实际边界要看 VSFilterMod 的输出。

也可以用一个特殊字符承载纹理，再用 `\fscx` 和 `\fscy` 调整字符区域，但这种写法不容易肉眼确认矩形尺寸。制作背景时，先在视频画面上截取无字幕参考图，在图像软件中按目标画布制作 PNG，再回到 Aegisub 定位。

### 让纹理移动

VSFilterMod 的扩展写法可以在 `\t` 内只传入 `png` 和移动参数，让同一张纹理在矩形区域内移动：

```text
Dialogue: 0,0:00:02.00,0:00:05.00,Default,,0,0,0,,{\an7\p1\pos(400,700)\bord0\shad0\1img(gradient.png)\t(0,3000,\1img(png,800,0))}m 0 0 l 1120 0 l 1120 180 l 0 180
```

这里的 `png` 是占位参数：所核对的实现进入 `\t` 动画时不会重新加载第一个参数指定的文件，只更新后面的纹理偏移。`x` 正值让纹理向左移，`y` 正值让纹理向下移；超出 PNG 边界会循环平铺。先用一张带方向标记的测试图片确认所用版本的表现，再换正式素材。

PNG 的像素尺寸应先在图像软件里准备好。这里核对的实现按图像像素读取并循环取样，没有提供随绘图矩形自动缩放纹理的参数；修改脚本画布、绘图缩放或视频尺寸后，应重新检查纹理大小与边缘。

## 预览、导出和排错

完成一段效果后，按下面的顺序检查：

1. 在 Aegisub 中确认脚本分辨率、样式和时间轴没有被改乱。
2. 用目标渲染器播放同一段。尤其是 `\1img`、复杂 `\t`、绘图和卡拉 OK，编辑器预览和实际播放可能不同。
3. 检查开头、中段和结尾，确认没有逐渐漂移、突然跳位或停留不退。
4. 用 Aegisub 的字体收集器整理字体；图片和 ASS 放在同一份工程目录，避免换电脑后路径失效。
5. 只做外挂字幕时保留 ASS 工程；需要压制或转 SUP 时，先输出短片段并逐帧比较，再处理全片。

如果普通标签有效而 PNG 挂图完全不显示，优先检查字幕源是否仍是 `libass`、图片路径是否存在、VSFilterMod 位数是否匹配，以及 `\1img` 是否被播放器过滤。若换成普通 `\p1` 矩形仍能显示，说明问题集中在扩展兼容性，而不是时间轴。
