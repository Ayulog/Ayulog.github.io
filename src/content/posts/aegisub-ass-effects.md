当字幕需要跟随画面物体移动、逐字变色，或者使用半透明底板与 PNG 纹理时，需要通过 ASS（Advanced SubStation Alpha）脚本在单条事件上编写定位、矢量绘图与动画标签。Aegisub 负责脚本编辑与时间轴对位，最终画面则由字幕渲染器（如 `libass`、VSFilter 或 VSFilterMod）实时绘制。

本文从建立 Aegisub 基础工程讲起，依次介绍常用 ASS 覆盖标签、多层底板排版、`\p1` 矢量绘图、卡拉 OK 模板，以及基于 VSFilterMod 扩展的 `\1img` 图片挂图写法。

## ASS 事件的组成与制作顺序

一条特效字幕在脚本和播放链路中由四个部分共同决定：

1. **文本与起止时间**：对白、歌词或画面注释文字，以及事件出现和消失的时间戳。
2. **全局样式（Style）**：定义字体、字号、四层颜色（主色、次色、边框、阴影）、描边粗细、对齐锚点和边距。
3. **行内覆盖标签（Override Tags）**：写在花括号 `{}` 内，对当前事件或局部文字临时覆盖位置、颜色并添加动态变换。
4. **目标渲染器**：负责解析标签并绘制图像。通用标签在 `libass` 和 VSFilter 中均可正常工作，而四角渐变（`\1vc`）与 PNG 挂图（`\1img`）则依赖 VSFilterMod 渲染组件。

实际制作时建议遵循**先校对文本与时间轴 → 建立基础样式与静态定位 → 叠加动画标签或卡拉 OK 模板 → 在目标渲染器中回看**的顺序。先把静态文字摆准，后续若某个动态标签未生效，更容易区分是坐标计算有误还是渲染器不支持该语法。

## 建立 Aegisub 基础工程

### 设置脚本画布（PlayRes）

在 Aegisub 中打开字幕并加载参考视频与音频后，先进入“文件 → 脚本属性”确认 `PlayResX` 和 `PlayResY`（高清片源通常设为 `1920` 与 `1080`）。

`PlayResX / PlayResY` 定义了 ASS 脚本的逻辑坐标系，`\pos(960,540)`、`\move` 以及字号、描边粗细都基于这块画布计算。开始编写定位和矢量图形前先固定画布尺寸；如果中途修改 `PlayRes` 或改变视频裁切比例，已写好的坐标都需要重新换算。初期调整位置时，可直接使用视频预览区左侧的可视化排版工具拖拽定位，观察编辑框中自动生成的标签参数。

### 建立基础样式表

打开“字幕 → 样式管理器”，为正片对白、双语副行、屏幕招牌和片尾歌词分别创建样式：

- **字体与字号**：优先选用目标环境已安装或准备封装进 MKV 的字体。
- **颜色与描边**：浅色画面下白字容易融进背景，搭配适当的描边（`\bord`）或阴影（`\shad`）通常比单纯加粗字体更清晰。
- **对齐方式与边距**：`\an1` 至 `\an9` 对应小键盘九宫格锚点，常规底部居中对白使用 `\an2`，顶部注释常用 `\an8`，左上角定位常用 `\an7`。

做复杂特效时，可以把基础样式设得尽量简洁，将局部字距、旋转和颜色变化留给单条事件的覆盖标签处理。

## 常用 ASS 覆盖标签与多层排版

### 核心覆盖标签速查

除强制换行符 `\N` 直接写在正文中外，其余覆盖标签均需写入 `{}` 内。需要注意：**ASS 标签中的颜色采用 `&HBBGGRR&`（蓝、绿、红）十六进制顺序**，与网页常见的 RGB 顺序相反；透明度则单独通过 `\alpha` 或 `\1a`–`\4a` 控制（`00` 为完全不透明，`FF` 为完全透明），不要把样式表里的 `&HAABBGGRR` 八位格式直接填入 `\1c`。

| 标签                       | 作用                       | 示例与说明                                                                                               |
| -------------------------- | -------------------------- | -------------------------------------------------------------------------------------------------------- |
| `\N`                       | 强制换行                   | `第一行\N第二行`                                                                                         |
| `\r`、`\rEng`              | 重置样式                   | `\r` 恢复当前事件指定的默认样式；`\rEng` 切换为样式表中的 `Eng` 样式（会清除该位置之前的覆盖标签与动画） |
| `\an1`–`\an9`              | 九宫格对齐锚点             | `\an7` 左上角对齐，`\an2` 底部居中对齐                                                                   |
| `\pos(x,y)`                | 静态坐标定位               | `\pos(960,900)`（与 `\move` 互斥，同一事件只用其一）                                                     |
| `\move(x1,y1,x2,y2,t1,t2)` | 按时间段直线移动           | `\move(300,900,1600,900,0,1200)`；末两项为相对当前事件起点的毫秒数，省略则在整条事件时长内移动           |
| `\fs`、`\fsp`              | 字号、字间距               | `\fs50\fsp15`                                                                                            |
| `\fscx`、`\fscy`           | 横向、纵向缩放比例（%）    | `\fscx80\fscy120`；默认值为 `100`                                                                        |
| `\frx`、`\fry`、`\frz`     | 绕 X、Y、Z 轴三维旋转      | `\frz10`；单位为度（°）                                                                                  |
| `\fax`、`\fay`             | 沿 X、Y 轴斜切变形         | `\fax0.05`；`0` 表示无斜切                                                                               |
| `\bord`、`\shad`           | 描边宽度、阴影距离         | `\bord2\shad0`                                                                                           |
| `\1c`、`\2c`、`\3c`、`\4c` | 主色、次色、描边色、阴影色 | `\1c&H786E5D&\3c&H000000&`；`\c` 等价于 `\1c`，`\2c` 主要用于卡拉 OK 变色前的预备色                      |
| `\alpha`、`\1a`–`\4a`      | 整体或单层透明度           | `\alpha&H80&` 为整体半透明；`\1a&HFF&\3a&H00&` 可隐藏字芯只显示描边                                      |
| `\blur`                    | 高斯模糊边缘               | `\bord2\blur3` 柔化描边；无描边（`\bord0`）时直接柔化字形边缘                                            |
| `\fad(t1,t2)`              | 淡入淡出                   | `\fad(120,200)` 表示片头 120 ms 淡入、片尾 200 ms 淡出                                                   |
| `\t(t1,t2,tags)`           | 动态标签插值变换           | `\t(0,800,\fscx120\fscy120)`；在 0 至 800 ms 内平滑放大至 120%                                           |
| `\clip(x1,y1,x2,y2)`       | 矩形遮罩裁剪               | `\clip(0,0,960,1080)` 仅显示左半屏区域内的字幕（支持配合 `\t` 动态裁剪或使用矢量路径裁剪）               |
| `\p1`、`\p0`               | 开启、关闭矢量绘图模式     | `\p1` 后接 `m`、`l`、`b` 等矢量绘图指令                                                                  |

例如，将一行白字黑边的标题定位于左上角，并在出现后的前 800 毫秒内平滑放大到 120%：

```text
Dialogue: 0,0:00:01.00,0:00:03.00,Default,,0,0,0,,{\an7\pos(120,120)\fs48\1c&HFFFFFF&\3c&H000000&\bord2\shad0\t(0,800,\fscx120\fscy120)}标题
```

### VSFilterMod 专有扩展标签

以下标签属于 VSFilterMod 分支的扩展实现，仅在挂载了 VSFilterMod 的播放器、Aegisub（切换至对应字幕提供器）或压制滤镜中生效：

| 标签            | 作用                  | 示例与说明                                                                              |
| --------------- | --------------------- | --------------------------------------------------------------------------------------- |
| `\fsvp`         | 后续字形的垂直偏移    | `\fsvp8`；正值上移、负值下移，作用于当前标签之后的文字字形                              |
| `\1vc`–`\4vc`   | 四角颜色渐变          | `\1vc(&H0000FF&,&H00FF00&,&HFF0000&,&HFFFFFF&)`；四个颜色依次对应左上、右上、左下、右下 |
| `\1img`–`\4img` | 用 PNG 纹理填充颜色层 | `\1img(panel.png)`；用外部 PNG 图像填充字形或矢量图形区域                               |

### 多图层叠加示例：带半透明底板与外框的标题

制作带底板和外框的注释条时，可将背景、边框和文字拆成三条起止时间完全相同的事件，分别设置图层 **Layer 0、1、2**（Layer 数值越大越靠上层显示）。以下示例基于 `1920×1080` 画布，前两条事件利用横向拉伸的实心方块字符 `█` 制作底板与线框，第三条放置正文：

```text
Dialogue: 0,0:00:01.00,0:00:03.00,Default,,0,0,0,,{\fscx2400\fscy100\an3\fs56\1c&H000000&\alpha&HE4&\bord0\shad0\b0\pos(1312.534,928.334)}█
Dialogue: 1,0:00:01.00,0:00:03.00,Default,,0,0,0,,{\fscx2400\fscy100\an3\fs56\1a&HFF&\3a&H00&\bord5\3c&H507782&\shad0\b0\pos(1312.534,928.334)}█
Dialogue: 2,0:00:01.00,0:00:03.00,Default,,0,0,0,,{\an3\fs50\1c&HFFFFFF&\alpha&H00&\bord0\shad0\b1\pos(1290,928)}示例标题文字
```

- **Layer 0**：半透明黑色填充（`\alpha&HE4&`），无描边（`\bord0`），作为半透明底板。
- **Layer 1**：将主色设为全透明（`\1a&HFF&`）、描边设为不透明（`\3a&H00&\bord5`），形成空心外框。前两条事件需使用同一款包含 `█` 字形的字体。
- **Layer 2**：叠在最上方的白色标题正文。

由于字符 `█` 的实际宽高与基线会随所选字体波动，如果需要精确控制底板的像素宽高，更推荐直接用下一节的 `\p1` 矢量绘图绘制矩形。

## 用 `\p1` 绘制矢量图形

开启 `\p1` 后，事件正文不再显示为普通文字，而是按坐标解析矢量绘图指令。这种方式不依赖外部图片，适合绘制字幕底板、遮罩色块、分割线和几何图形：

```text
Dialogue: 0,0:00:01.00,0:00:03.00,Default,,0,0,0,,{\an7\pos(100,100)\p1\bord0\shad0\1c&H3B82F6&}m 0 0 l 240 0 l 240 64 l 0 64
```

上例中 `m 0 0` 将画笔移至起点 `(0,0)`，随后的 `l` 依次连接 `(240,0)`、`(240,64)`、`0,64)` 并自动闭合，绘制出一个宽 240、高 64（基于脚本画布坐标）的蓝色矩形，且左上角通过 `\an7\pos(100,100)` 定位于画布 `(100,100)` 处。

若要在同一条事件的矢量图后面接着写文字，可在绘图指令末尾加上 `{\p0}` 退出绘图模式；不过实际排版中更习惯把矢量底板（Layer 0）和文字（Layer 1）拆成两条独立事件，分别调整位置、透明度和进出场动画（`\fad` / `\t`）。

## 卡拉 OK 音节切分与模板应用

ASS 原生提供 `\k`、`\kf`（或 `\K`）、`\ko` 等卡拉 OK 标签，时间单位为**厘秒（0.01 秒）**。例如：

```text
{\k20}你{\k30}好
```

代表“你”持续 0.20 秒，“好”持续 0.30 秒。制作卡拉 OK 特效分为两步：

1. **结合音频波形切分音节（K 轴）**：在 Aegisub 音频区开启卡拉 OK 模式，听原曲将每句歌词按发音节拍切分并对齐波形。先用两三个音节测试 `\k`（硬切换）、`\kf`（平滑填充）与 `\ko`（描边填充）的区别，再完成全曲 K 轴。
2. **使用 Karaoke Templater 套用特效模板**：Aegisub 内置了 [Karaoke Templater 自动化脚本][aegisub-templater]。先在字幕顶部建立标记为 `template line` 或 `template syl` 的注释行（写在 Effect 栏），编写包含 `$syl`、`$start`、`$end` 等变量的标签代码，再点击“自动化 → 应用卡拉 OK 模板（Apply karaoke template）”，即可根据切好的 K 轴批量生成逐字或逐音节的粒子、位移与渐变事件。

参考现成模板（如 [Aegisub Karaoke Effect 481 Templates][k-templates] 或[青空的双语特效模板教程][air-moe]）时，先核对模板要求的样式名称（Style）与画布分辨率（`PlayResX / PlayResY`）是否与当前工程一致；应用模板后在预览区检查生成事件，若修改了歌词或时间轴，直接修改原始 `karaoke` 行并重新运行模板即可覆盖更新。

## 进阶：基于 VSFilterMod 的 PNG 挂图

### 渲染器前提与播放设置

VSFilterMod 提供了 `\1img`、`\2img`、`\3img`、`\4img` 扩展标签，支持将带透明通道的外部 PNG 图片作为纹理填充到主色、次色、描边或阴影层。

由于标准 `libass` 渲染器不支持该语法，使用前需明确目标播放或压制链路：

- **本地外挂播放**：需在 PotPlayer 或 MPC-HC 中注册并挂载对应位数（32 位 / 64 位）的 `VSFilterMod.dll`，配置步骤见 [PotPlayer 和 MPC-HC 挂载 VSFilterMod 加载外挂特效字幕](/posts/vsfiltermod-external-subtitles/)。
- **压制或转 SUP**：需通过 VapourSynth / AviSynth 调用支持该扩展的 VSFilterMod 插件将字幕压入画面，或渲染成 BDN XML + PNG 后编码为 PGS 图形字幕（见[字幕处理教程第六步](/posts/subtitle-workflow/#第六步渲染并转回-sup)）。

### 用矩形绘图区承载静态 PNG

挂载 PNG 纹理的标准做法是：先用 `\p1` 画出与 PNG 实际像素宽高完全一致的矩形，再用 `\1img` 将图片填满该矩形。将 `panel.png`（假设尺寸为 `880×226`）与 `.ass` 文件放在同一目录下：

```text
Dialogue: 0,0:00:02.00,0:00:05.00,Default,,0,0,0,,{\an7\p1\pos(888,784)\bord0\shad0\1img(panel.png)}m 0 0 l 880 0 l 880 226 l 0 226
```

编写要点：

- **路径解析**：VSFilterMod 默认相对于 `.ass` 所在目录寻找图片（支持 `images/panel.png` 这类相对子路径），打包工程时保持相对目录结构即可避免跨机路径失效。
- **尺寸与锚点**：绘图尺寸 `880×226` 与 PNG 像素尺寸保持 1:1 对应，配合 `\an7`（左上角对齐）和 `\pos(888,784)` 即可精确控制图片在 `1920×1080` 画布上的位置。若绘图框大于图片尺寸，PNG 纹理会在框内循环平铺。
- **清理干扰层**：加上 `\bord0\shad0` 关闭默认描边与阴影，避免在透明 PNG 四周画出多余的矩形黑框。

### 在 `\t` 中实现纹理滚动动画

如果希望让一张长条渐变图或图案纹理在固定矩形框内平滑滚动，可以在 `\t` 中传入 `\1img(png,偏移X,偏移Y)`：

```text
Dialogue: 0,0:00:02.00,0:00:05.00,Default,,0,0,0,,{\an7\p1\pos(400,700)\bord0\shad0\1img(gradient.png)\t(0,3000,\1img(png,800,0))}m 0 0 l 1120 0 l 1120 180 l 0 180
```

在 VSFilterMod 的实现中，进入 `\t` 动态变换时无需重复解析图片路径，第一个参数固定写占位符 `png`，后两个参数控制纹理的水平与垂直滚动偏移量（超出图片边界时自动循环平铺）。由于 VSFilterMod 直接按 PNG 原生像素取样，需要缩放挂图尺寸时，应先在图像软件中将 PNG 导出为目标像素大小，再回 Aegisub 调整绘图矩形。

## 成品预览与常见问题排查

特效编写完成后，按以下清单做最终检查：

1. **跨渲染器复核**：从 Aegisub 保存工程后，用目标播放器或压制预览工具实际播放一遍，重点核对复杂 `\t` 变换、矢量遮罩（`\clip`）、卡拉 OK 与 `\1img` 在目标渲染器下的表现。
2. **排查 PNG 挂图不显示**：若普通 ASS 标签正常而 `\1img` 完全空白，先暂时去掉 `\1img(...)` 并加上 `\1c&HFFFFFF&`，检查 `\p1` 矩形本身是否出现在正确的时间与坐标上；若矩形正常显示，再核对播放器是否成功挂载了 `VSFilterMod.dll` 以及 PNG 相对路径是否正确。
3. **打包字体与图片资产**：运行“文件 → 字体收集器”将工程用到的字体导出至项目目录，连同 `.ass` 与引用的 PNG 图片一并归档保存。
