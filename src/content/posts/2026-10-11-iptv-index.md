## IPTVindex 里看什么

IPTVindex 是外链导航，首页按直播、点播、音乐、在线和其他分区，收录播放器、直播源、节目单与工具。找资源后，还要进入对应项目看当前说明。

| 入口                                | 这篇用到的内容                                                 |
| ----------------------------------- | -------------------------------------------------------------- |
| [直播](https://iptvindex.com/#iptv) | 找播放器、直播列表和 EPG，查看酷9等客户端的配置说明            |
| [在线](https://iptvindex.com/#web)  | 找央视和地方广电的官方网页直播入口                             |
| [点播](https://iptvindex.com/#vod)  | 与直播分开看；站内原有的自建聚合点播接口已标注“即日起不再开放” |

导航里的下载入口有项目页、论坛和网盘等不同来源，不能把每个链接都当作软件的官方发布页。版本、适配系统和安装方法以维护者当前说明为准。

## 先分清手里的地址

| 地址类型         | 内容                                 | 放在哪里                         |
| ---------------- | ------------------------------------ | -------------------------------- |
| 导航页、项目首页 | 网页说明和下载链接                   | 浏览器打开，继续找实际订阅地址   |
| M3U 频道列表     | 频道名称、分组、台标和流地址等       | 播放器的播放列表或直播订阅入口   |
| 单频道流地址     | 一个频道的音视频；可能是 HLS `.m3u8` | 播放器打开网络流，或收进频道列表 |
| XMLTV 节目单     | 节目名称、频道标识和播出时间         | 支持 EPG 的播放器中的节目单入口  |

不能只看扩展名判断用途。`.m3u8` 也可能是单频道 HLS 流的播放清单；一个没有扩展名的接口也可能返回 M3U。关键是地址实际返回什么。

例如，`https://iptvindex.com/` 是导航页，不能直接填进播放器的直播订阅框。下面的 IPTV-org 地址才是频道列表。

## 找一份直播列表

[IPTV-org](https://github.com/iptv-org/iptv) 收集公开可访问的直播流，并提供按语言、国家与内容分类整理的列表。初次导入可以先用中文列表，方便核对频道和播放情况：

```text
https://iptv-org.github.io/iptv/languages/zho.m3u
```

需要其他范围时，到项目的 [播放列表说明](https://github.com/iptv-org/iptv/blob/master/PLAYLISTS.md) 选对应入口：

| 列表     | 地址                                                |
| -------- | --------------------------------------------------- |
| 全部频道 | <https://iptv-org.github.io/iptv/index.m3u>         |
| 中文频道 | <https://iptv-org.github.io/iptv/languages/zho.m3u> |
| 中国频道 | <https://iptv-org.github.io/iptv/countries/cn.m3u>  |

“中文”和“中国”分别按语言与播出地区筛选，结果不相同。频道数量也会随维护变化，没必要把某次的数量当作固定指标。

核对时，总表和中文列表都返回了以 `#EXTM3U` 开头的内容。这说明列表地址可读取，不代表其中所有流都能在当前网络播放。项目的频道数据库也可能有频道资料而没有流地址，具体见 [FAQ](https://github.com/iptv-org/iptv/blob/master/FAQ.md)。

导航上的旧介绍可能落后于项目调整。例如 [fanmingming/live](https://github.com/fanmingming/live) 当前 README 主要介绍电视、广播台标库与相关工具，不能仅凭旧的“直播源”印象把它当作完整可用的频道订阅。

## 导入电脑和电视播放器

### 电脑：用 VLC 打开列表

从 [VideoLAN 官网](https://www.videolan.org/vlc/) 获取 VLC。Windows 版可按官方的[网络串流说明](https://docs.videolan.me/vlc-user/desktop/3.0/en/basic/media.html#playing-a-network-stream)操作：

1. 打开 **媒体 → 打开网络串流**（Media → Open Network Stream）。
2. 在网络地址框粘贴上面的中文 M3U 地址，点击播放。
3. 打开播放列表视图，选择具体频道。若某个频道失败，换几个频道对照，再检查失败流的网络条件。

这一段用于检查列表读取与播放。下面的 XMLTV 配置需要客户端本身支持外部 EPG，不能把节目单地址填到 VLC 的网络串流框里当直播播放。

### 电视：以酷9的订阅入口为例

IPTVindex 的酷9说明提到，首次没有列表时会黑屏，需要自行导入直播源。页面给出的入口是：

- **列表配置 → 列表订阅**：填写直播列表地址。
- **列表配置 → EPG订阅**：填写节目单地址。

保存后刷新订阅，检查是否出现频道，再试播。这套菜单是酷9的用法；换成其他播放器，要找它自己的 M3U、直播订阅和 EPG 设置。

酷9的[维护者说明帖](https://www.right.com.cn/FORUM/thread-8427797-1-1.html)记录了多列表订阅、频道搜索和 XML 格式 EPG 等功能。回看、时移还需要直播源支持，添加节目单本身不会增加回看能力。

## 给频道补上节目单

直播列表负责找到视频，EPG 负责显示“现在播什么、接下来播什么”。[EPG.PW](https://epg.pw/xmltv.html?lang=zh-hans) 按国家和地区提供 XMLTV 文件，可在列表页选择需要的范围。

中国地区的 XML 示例：

```text
https://epg.pw/xmltv/epg_CN.xml
```

页面也提供 `.xml.gz` 压缩版本。播放器是否能直接读取 gzip 文件，要看客户端说明；不确定时先用它明确支持的格式。

填好地址后，主要核对三件事：

1. **节目单是否下载成功**：EPG 文件只包含节目资料，不会提供视频流。
2. **频道是否匹配**：M3U 中的 `tvg-id` 通常要对应 XMLTV 的频道 ID；有些播放器也支持按名称或手动映射，具体规则看客户端。
3. **时间是否正确**：检查设备时间、节目单时区和播放器偏移设置。只有统一偏移时再考虑调整偏移量，不要用时间设置掩盖频道匹配错误。

这里没有验证 IPTV-org 中文列表与 EPG.PW 的频道标识能否全部自动对应。某个频道有画面但没有节目单时，先检查该频道的 ID 与映射，不必重新配置视频源。

## 播放与节目单排错

| 现象                 | 优先检查                                                                         |
| -------------------- | -------------------------------------------------------------------------------- |
| 导入后没有频道       | 地址是否返回 M3U，而不是网页、登录页或错误提示；播放器是否支持该列表格式         |
| 有频道名但没有画面   | 单频道流是否失效、需要鉴权或有地区限制；列表可下载不代表流可访问                 |
| 电脑能看，电视不能看 | 两台设备的 DNS、IPv4 / IPv6 连通性与解码能力是否相同；电脑上的代理不一定覆盖电视 |
| 只有 IPv6 源播不了   | 播放设备是否真的有可用的 IPv6 连接，源所在网络是否可达                           |
| 有画面，没有节目单   | EPG 下载、频道 ID 和映射规则                                                     |
| 节目单整体错几个小时 | 设备时间、节目单时区和客户端偏移设置                                             |
| 频道失效后一直不更新 | 订阅是否刷新成功；上游列表是否已经替换该流                                       |

如果后续要统一维护家里多台设备的列表、频道分组与订阅入口，可以改用 [NAS 上的服务端整理方案](/posts/2026-10-10-iptv-guide/)。服务端整理能减少重复维护，但不能修复上游已经失效的流。

## 直接看官方直播网页

只看少量频道时，也可以从 IPTVindex 的“在线”栏目进入电视台网页。例如[央视直播大全](https://tv.cctv.com/live/)可直接在浏览器中访问，省去管理 M3U 和 EPG 的步骤。

网页地址仍然是网页入口，不应直接当作播放器订阅；是否提供可供外部播放器使用的流，另看电视台公开说明。
