影视资源文件名中，片名、年份与 `S01E01` 用于定位具体作品，而 `2160p`、`WEB-DL`、`HEVC`、`DDP5.1` 等字段则用于标记片源、编码与音轨规格。下载选片时主要看发布名中的技术参数，整理入库时则需要转换为媒体服务器易于识别的目录与文件命名。

下文以虚构片名演示发布名拆解，并参照 Emby 官方规范整理电影、剧集、外挂字幕及多版本命名。相关工具见 [NAS 服务清单](/posts/nas-software-websites/)。

## 发布名与入库名的用途

| 命名类型     | 核心用途                                     | 重点保留的字段                                   |
| ------------ | -------------------------------------------- | ------------------------------------------------ |
| 资源发布名   | 说明片源出处与压制规格，便于检索和选片       | 片名、年份、季集、片源、视频编码、音轨、发布组   |
| 媒体库入库名 | 供 Emby 等服务端匹配元数据、分季分集与挂字幕 | 片名、年份、季集编号，按需附加数据库 ID 与版本名 |

发布名由各站点与制作组按惯例拼接，字段顺序和分隔符并不完全固定；而在媒体库刮削时，准确的作品名、上映年份和季集号比冗长的技术后缀更关键。

## 资源发布名结构拆解

以一条典型的 4K 电影发布名为例：

```text
Example.Movie.2024.2160p.UHD.BluRay.REMUX.HDR.HEVC.TrueHD.7.1.Atmos-Group.mkv
```

| 字段               | 含义说明                                           |
| ------------------ | -------------------------------------------------- |
| `Example.Movie`    | 影片英文名，单词之间常以英文句点 `.` 代替空格      |
| `2024`             | 电影首映年份，用于区分同名或翻拍作品               |
| `2160p`            | 分辨率档位，对应家用 4K UHD（3840 × 2160）         |
| `UHD.BluRay`       | 片源媒介，此处为 4K UHD 蓝光原盘                   |
| `REMUX`            | 制作方式：提取原盘音视频轨直接重封装，不重编码画面 |
| `HDR`              | 高动态范围标识（具体为 HDR10 或杜比视界需看详情）  |
| `HEVC`             | 视频编码标准 H.265                                 |
| `TrueHD.7.1.Atmos` | 杜比 TrueHD 无损音轨、7.1 声道布局，带全景声元数据 |
| `-Group`           | 连字符后为发布组或制作组名称                       |
| `.mkv`             | Matroska 容器扩展名                                |

再看一条流媒体剧集发布名：

```text
Example.Series.2024.S02E03.1080p.WEB-DL.DDP5.1.H.264-Group.mkv
```

其中 `S02E03` 代表第二季第三集，`WEB-DL` 代表流媒体平台直下片源，`DDP5.1` 代表 Dolby Digital Plus 5.1 声道音轨，`H.264` 为视频编码标准。不同发布组可能会调换音轨与视频编码字段的前后顺序，含义保持一致。

## 片名、年份与季集

### 片名与年份

整理媒体库前，建议先在所用刮削源（如 [TMDB][tmdb] 或 [IMDb][imdb]）核对目标条目：

- **上映年份**：电影文件名中的年份填写作品首映年份（与蓝光碟发售年份或重制年份区分开）；若不同地区跨年上映导致年份有出入，以 TMDB 对应条目的显示年份为准。
- **剧集首播年份**：电视剧总文件夹通常标注第一季首播年份，各季内容通过子文件夹和 `S01`、`S02` 区分。
- **同名消歧**：遇到同名电影或译名容易混淆的作品，可在文件夹名中直接附上 TMDB / IMDb 数据库 ID。

### 季号与集号标记

| 标记                    | 含义                   | 整理入库要点                                       |
| ----------------------- | ---------------------- | -------------------------------------------------- |
| `S01E01`                | 第一季第一集           | 标准单集命名格式                                   |
| `S01`                   | 第一季整季包           | 入库时仍需确保每个单集文件带有具体的 `E01`、`E02`  |
| `S01E01-E02`            | 单文件合并第一、二集   | 适用于两集合并为一个视频文件的情况                 |
| `S00E01`                | 特别篇（Specials）首集 | 编号需与 TMDB 该剧集 `Season 00` 中的条目顺序对应  |
| `EP01`、`E01`、绝对集数 | 按总集数连续编号       | 常见于长篇连载番剧或综艺，入库前需核对分季映射关系 |

整理剧集时需留意合并集、上下集、特别篇以及电视播出顺序与 DVD/BD 光盘收录顺序的差异，先抽查首尾几集的标题与正片内容，避免按文件名盲目递增重命名导致整季错位。

## 片源与制作方式

| 标记                        | 常见含义                                           | 技术特点与注意事项                                |
| --------------------------- | -------------------------------------------------- | ------------------------------------------------- |
| `BDMV`、`BDISO`             | 蓝光原盘目录结构或 ISO 光盘镜像                    | 完整保留原盘菜单、正片与花絮，体积最大            |
| `BluRay`、`BDRip`           | 源自蓝光原盘的资源（常配合 `x264` / `x265` 压制）  | 经过重新编码压缩以平衡画质与体积                  |
| `REMUX`                     | 提取原盘主视频轨与所需音轨/字幕，直接封装为 MKV/TS | 画质与原盘一致，省去菜单、花絮及不需要的外语音轨  |
| `WEB-DL`                    | 从网络流媒体平台直接下载并封装的音视频流           | 保留平台下发的原始流，上线速度快                  |
| `WEBRip`                    | 对网络流媒体源进行二次压制或录制的版本             | 部分制作组用于对高码率流媒体源做二次编码体积优化  |
| `HDTV`、`HDTVRip`           | 数字高清电视广播录制的 TS 流或重压制版             | 可能带有电视台台标、跑马灯或隔行扫描（`1080i`）   |
| `DVD`、`VIDEO_TS`、`DVDRip` | DVD 原盘结构或基于 DVD 压制的标清资源              | 常见于未发行高清蓝光的早期影视或独家版本          |
| `CAM`、`TS`、`TC`           | 早期非正式片源（影院摄录、外接音源或胶片数字转录） | 画质与音质受限，注意区分此处的 `TS` 与 `.ts` 容器 |

选片时可结合自身存储空间与播放设备考量：追求原盘画质且希望方便播放器直放、挂载外挂字幕时，常选 `REMUX`；兼顾画质与硬盘空间可选知名压制组的 `BluRay x265 / x264`；追新剧或流媒体独占内容则以 `WEB-DL` 为主。

## 分辨率、编码与 HDR

### 分辨率与扫描方式

| 标记              | 规格说明                                                  |
| ----------------- | --------------------------------------------------------- |
| `720p`            | 标准画布 1280 × 720，逐行扫描                             |
| `1080p`           | 标准画布 1920 × 1080，逐行扫描                            |
| `1080i`           | 1080 线隔行扫描（常见于电视录制源与部分演唱会蓝光）       |
| `2160p`、`4K UHD` | 家用超高清标准画布 3840 × 2160（影院 DCI 4K 宽度为 4096） |

部分宽银幕电影在重编码压制时会裁去上下黑边（例如实际分辨率为 `1920 × 800` 或 `3840 × 1600`），只要水平宽度达到对应标准，发布名仍标为 `1080p` 或 `2160p`。实际画面观感除分辨率与帧率（如 `24fps`、`60fps`）外，还取决于母版质量、码率及压制参数。

### 视频编码标准与编码器

| 标记            | 含义说明                                                |
| --------------- | ------------------------------------------------------- |
| `H.264`、`AVC`  | 同一视频编码标准的两种称呼，设备兼容性最广              |
| `x264`          | 用于压制生成 H.264 视频流的开源软件编码器               |
| `H.265`、`HEVC` | 高效视频编码标准，4K 资源主流格式                       |
| `x265`          | 用于压制生成 HEVC 视频流的开源软件编码器                |
| `AV1`           | 新一代免版税编码标准，需确认播放器与硬件是否支持硬解    |
| `10bit`         | 色彩位深标记（平滑渐变、减少色带，SDR 与 HDR 均可采用） |

在发布名中，原盘 REMUX 或流媒体 WEB-DL 通常直接标注编码标准 `AVC` / `H.264` 或 `HEVC` / `H.265`；而经过压制组二次重编码的资源则会直接标注所使用的编码器 `x264` 或 `x265`。更多编码与压制工具背景见[压制软件与资料清单](/posts/encode-software/)。

### 动态范围（HDR / 杜比视界）与位深

`SDR`、`HDR10`、`HDR10+`、`DV` / `DoVi`（Dolby Vision，杜比视界）与 `HDR Vivid` 描述视频的动态范围与色彩元数据格式：

- **分辨率与动态范围独立**：`2160p` 与 `10bit` 仅代表像素尺寸和色彩位深，4K 视频同样存在 SDR 版本。
- **杜比视界 Profile 兼容**：标注 `DV` / `DoVi` 的资源细分为不同 Profile（如流媒体常见的单层无 HDR10 兼容底层的 Profile 5，以及蓝光原盘常见的带 HDR10 兼容层的 Profile 7 / 8）。若播放设备或显示器不支持杜比视界且视频不含 HDR10 回退层，直接播放可能出现画面偏紫或偏绿，选购前需结合自身播放链路确认。

## 音轨、字幕与容器

### 音频编码、声道与语言

| 标记                   | 含义说明                                     |
| ---------------------- | -------------------------------------------- |
| `AAC`                  | 常见有损音频编码，广泛用于流媒体与压制版     |
| `AC3`、`DD`            | Dolby Digital（杜比数字），有损环绕声编码    |
| `E-AC-3`、`DDP`、`DD+` | Dolby Digital Plus，流媒体平台主力环绕声格式 |
| `DTS`                  | DTS 有损核心音轨                             |
| `TrueHD`               | Dolby TrueHD，蓝光原盘常用的无损音频编码     |
| `DTS-HD MA`            | DTS-HD Master Audio，蓝光常用的无损音频编码  |
| `FLAC`、`LPCM`、`PCM`  | 无损压缩或未压缩数字音频轨道                 |
| `2.0`、`5.1`、`7.1`    | 声道布局（`.1` 代表低频效果 LFE 低音炮声道） |
| `Atmos`、`DTS:X`       | 基于对象的三维沉浸式音频技术标识             |

注意 `Atmos`（杜比全景声）本身是空间音频元数据，既可以封装在蓝光原盘的无损 `TrueHD` 音轨上（`TrueHD 7.1 Atmos`），也可以封装在流媒体的有损 `DDP` 音轨上（`DDP 5.1 Atmos`）。此外，`Dual Audio`、`2Audios`、`国粤英` 等标记代表内封多条语言音轨，播放时可在音轨菜单中切换。

### 字幕的三种封装形式

- **内封字幕**：封装在 `.mkv` 等容器内部，支持在播放器菜单中自由切换或关闭。
- **外挂字幕**：与视频存放在同目录的独立 `.srt`、`.ass`、`.sup` 文件，通过相同的文件名前缀自动关联。
- **硬字幕（内嵌字幕）**：文字已直接压制进视频画面像素中，无法关闭或调整样式。

格式方面，`.srt` 为纯文本字幕，兼容性最好；`.ass` / `.ssa` 支持字体、定位与特效；蓝光原盘提取的 `PGS`（`.sup`）则为图形字幕，若客户端不支持直接渲染图形字幕，媒体服务器可能会触发视频转码以烧录字幕。

### 容器格式（MKV 与 MP4）

`.mkv`（Matroska）和 `.mp4` 是用于装载视频轨、音频轨、字幕轨和章节信息的封装容器。MKV 对多音轨、多内封字幕及杜比TrueHD / PGS 字幕的封装支持更为灵活；而客户端能否直接播放（Direct Play），由容器格式与内部音视频编码共同决定。

## 版本与发布组标记

| 标记               | 含义说明                                         |
| ------------------ | ------------------------------------------------ |
| `Theatrical`       | 院线公映版                                       |
| `Extended`         | 加长版                                           |
| `Director's Cut`   | 导演剪辑版                                       |
| `Unrated`          | 未分级版                                         |
| `Remastered`       | 数字修复版或周年重制版                           |
| `IMAX`             | 包含 IMAX 扩展画幅片段的版本                     |
| `PROPER`、`REPACK` | 修正此前发布版本压制瑕疵或音画不同步后的重发版本 |

整理同一部电影的不同剪辑版本（如院线版与导演剪辑版）时，由于正片时长不同，外挂字幕的时间轴往往不通用，建议在文件名中保留版本标识以便区分。

## 电影入库命名规则

参照 [Emby 电影命名规则][movie-naming]，建议为每部电影单独建立文件夹，以“片名 (年份)”命名：

```text
movies/
└── Example Movie (2024)/
    ├── Example Movie (2024).mkv
    ├── Example Movie (2024).zh.srt
    └── Example Movie (2024).en.srt
```

外置字幕以视频文件的完整主文件名开头，后接语言代码（如 `zh`、`chs`、`cht`、`en`）及可选的 `default`（默认加载）、`forced`（强制字幕，仅翻译外语片段或标牌）标记（详见 [Emby 字幕命名规则][subtitles]）：

```text
Example Movie (2024).zh.default.srt
Example Movie (2024).en.forced.srt
```

### 附加数据库 ID 消除同名歧义

遇到重名电影或冷门作品时，可在文件夹名中直接标注 TMDB 或 IMDb ID：

```text
Example Movie (2024) [tmdbid=12345]
```

### 同一电影保留多个版本

若希望让 Emby 将不同分辨率或剪辑规格合并到同一个电影条目下供播放时切换，可将它们放在同一个电影文件夹内，视频文件名以**完整文件夹名加 `-`（空格+连字符+空格）**开头，后接版本标签：

```text
movies/
└── Example Movie (2024)/
    ├── Example Movie (2024) - 1080p SDR.mkv
    ├── Example Movie (2024) - 1080p SDR.zh.srt
    ├── Example Movie (2024) - 2160p HDR.mkv
    └── Example Movie (2024) - 2160p HDR.zh.srt
```

客户端在详情页即可直接下拉选择 `1080p SDR` 或 `2160p HDR` 版本播放。

## 剧集入库命名规则

参照 [Emby 剧集命名规则][tv-naming]，每部剧集建立一个总目录，其下按季建立 `Season XX` 子目录，单集文件名标明 `SXXEXX`：

```text
tv/
└── Example Series (2024)/
    ├── Season 01/
    │   ├── Example Series (2024) - S01E01.mkv
    │   ├── Example Series (2024) - S01E01.zh.srt
    │   └── Example Series (2024) - S01E02.mkv
    ├── Season 02/
    │   └── Example Series (2024) - S02E01.mkv
    └── Season 00/
        └── Example Series (2024) - S00E01.mkv
```

- **特别篇（`Season 00`）**：用于存放 TMDB `Specials` 季中收录的 OVA、SP 或剧场版特典，集号需与 TMDB 条目严格对应。
- **合并集命名**：当单个视频文件连续包含两集内容时，命名为 `Example Series (2024) - S01E01-E02.mkv`，媒体库会将第一集与第二集同时关联到该文件。

## 兼顾媒体库整理与下载器保种

为了在不影响 PT / BT 做种的前提下将文件名整理为标准入库格式，通常将下载目录与媒体库目录分开放在同一文件系统下：

```text
data/
├── downloads/       # 保留下载器做种所需的原始发布文件名
└── library/
    ├── movies/      # 通过硬链接生成的标准电影目录
    └── tv/          # 通过硬链接生成的标准剧集目录
```

通过 MoviePilot 等工具使用**硬链接（Hardlink）**整理时，下载目录与媒体库目录中的文件共享同一份底层磁盘数据，只占用一份空间，重命名或删除媒体库中的硬链接也不会破坏下载器的做种校验。批量处理前，建议先用一部电影和一两集剧集完成从硬链接整理、Emby 刮削到字幕加载和做种状态核对的全流程验证。

## 用 MediaInfo 核对真实参数

当发布名标注不够详细或需要排查播放兼容性时，可使用 [MediaInfo][mediainfo]（切换为“文本”或“树状图”视图）查看文件内部封装的真实轨道参数：

| 检查项                         | 核对内容                                          |
| ------------------------------ | ------------------------------------------------- |
| 容器格式、时长、总码率         | 确认封装格式与完整时长，排查文件截断或损坏        |
| 视频编码、Profile 与位深       | 确认是 AVC、HEVC 还是 AV1，以及客户端硬解是否支持 |
| 画面宽高、帧率与扫描方式       | 查看实际像素尺寸、是否裁黑边、是否隔行扫描        |
| 色彩空间与 HDR 元数据          | 核对 SDR、HDR10 或 Dolby Vision 的具体 Profile    |
| 音频编码、声道数、语言与默认轨 | 确认包含所需语言音轨及具体的无损/有损格式         |
| 内封字幕格式、语言与强制标记   | 查看内封字幕为 SRT、ASS 还是 PGS 图形字幕         |

## 常见问题

| 现象                                   | 排查与处理建议                                                                                 |
| -------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 文件名已按规范整理，但刮削结果依然错误 | 检查媒体库类型（电影/电视节目）是否选错、目录层级是否过深，或在文件夹名补充 `[tmdbid=...]`     |
| 只保留中文片名能否正常刮削             | 可以，建议采用 `中文片名 (年份)` 格式，同名作品较多时附上数据库 ID 即可准确匹配                |
| 下载了 `2160p REMUX TrueHD` 播放却卡顿 | 检查客户端与电视/功放是否支持直通解码 TrueHD、杜比视界及高码率网络传输，避免触发服务端软解转码 |
| 外挂字幕已放入同目录，但播放器里看不到 | 确认字幕文件名前缀与视频文件名完全一致，并检查容器挂载权限是否可读                             |
